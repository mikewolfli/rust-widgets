# Support

## Getting help

- Read the README and docs in `docs/` first.
- Check existing issues before opening a new one.
- Use issue templates for bug reports and feature requests.

## What to include

- OS and version
- Rust version (`rustc --version`)
- Minimal reproduction
- Error logs or screenshots

## Project scope

This repository focuses on cross-platform Rust GUI architecture. For unrelated
questions, please use community discussion channels.
