# Exemptions for tools/check_click_requires_release_inside.sh (BLUE22 §6.7).
#
# The rule and the full statement of what the gate proves and does not prove are in that script's
# header. Read it first. In short: a control that emits `clicked` and handles `Event::MouseRelease`
# must either test containment on the release, or abandon the press on `MouseLeave`, or be listed
# here with the mechanism its containment actually rests on.
#
# Format, one record per line, whitespace-separated (the reason may contain spaces):
#
#     src/path/to/control.rs    <mechanism>    <why this is not a release-outside defect>
#
# A bare path is not an entry: an exemption without a mechanism and a reason is an unexplained
# licence, which this project forbids. The first field is matched against the path the scan
# produces, so a moved file stops being exempt rather than silently staying so.
#
# EVERY ENTRY BELOW IS A VERIFIED DEFECT OR A VERIFIED ALTERNATIVE MECHANISM — none is a
# "looks fine to me". Each one names the line the scan reported and the evidence for the verdict.
#
# ─────────────────────────────────────────────────────────────────────────────
# These three are exempted because the click lives on the PRESS arm, not the release arm.
#
# The gate's population is "emits clicked AND handles MouseRelease", which is the right population
# for the rule but a superset of the paths the rule is about: a control whose release arm only
# clears a latch cannot fire on a release outside it, because it does not fire on a release at all.
# The click on the press arm is a different interaction contract with its own defect class (a press
# inside is always a press inside), and `grid` bounds it, `radar_chart` does not — see below.
# ─────────────────────────────────────────────────────────────────────────────

# Verified: the containment is real, in a helper the scan's vocabulary cannot name.
# `cell_at` -> `cell_at_y` (grid.rs:154) and `cell_at_x` (grid.rs:174) each return `None` when the
# coordinate lies outside `base.geometry()`, so a point outside the control resolves to no cell and
# `clicked.emit()` on the press arm (grid.rs:452) is unreachable. The release arm (grid.rs:456) only
# clears `mouse_pressed` and emits nothing.
src/widget/special_widgets/grid.rs    press-arm-only    containment via cell_at, which bounds-checks rect in cell_at_y/cell_at_x

# FIXED — `radar_chart` and `property_grid` were recorded here as live defects and both are now
# guarded at the source, so their entries are gone rather than kept as stale licences (a stale
# exemption is worse than none: it would silently cover the next defect in the same file).
#
#   radar_chart.rs  `axis_at` now returns `None` for a point outside the control, so the press arm
#                   cannot resolve an axis for a press that never touched the chart.
#   property_grid.rs The press/release arm now returns early for a point outside the grid, so a
#                   press left of, right of or below it can no longer select a row by `y` alone.
#
# Both fixes are pinned by tests that drive the control with a point outside its geometry and assert
# `clicked` stays silent -- see each control's own test module.
