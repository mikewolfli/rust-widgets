# 国际化（i18n）

rust-widgets 提供了一个完整的国际化系统，包括基于 JSON 的翻译文件、编译时宏、复数形式、上下文感知翻译以及通过文件系统监视实现的热重载。

---

## 1. `I18nManager` — 语言注册表

`I18nManager` 是核心的 i18n 注册表。它从 JSON 文件加载翻译、切换活动语言、并使用复数和上下文支持解析翻译键。

```rust
use rust_widgets::i18n::I18nManager;

let mut manager = I18nManager::new();

// 加载翻译文件
manager.load_translations("language/en.json").unwrap();
manager.load_translations("language/zh-cn.json").unwrap();
manager.load_translations("language/zh-tw.json").unwrap();

// 设置活动语言
manager.set_language("zh-cn");
println!("活动语言: {}", manager.current_language());

// 翻译一个键
let text = manager.translate("common.button.ok");
assert_eq!(text, "确定");
```

---

## 2. 翻译文件格式

翻译文件是 JSON 文档，包含一个 `language` 标识符和一个 `translations` 映射。每个翻译条目包含一个 `message`，以及可选的 `context` 和 `plural` 字段。

### 文件: `language/en.json`

```json
{
  "language": "en",
  "translations": {
    "common.button.ok": {
      "message": "OK"
    },
    "common.button.cancel": {
      "message": "Cancel"
    },
    "dialog.file_dialog.open_file": {
      "message": "Open File"
    },
    "items.count": {
      "message": "1 item",
      "plural": {
        "0": "No items",
        "1": "1 item",
        "2": "{{count}} items"
      }
    },
    "file.saved": {
      "context": "status_bar",
      "message": "File saved successfully"
    },
    "file.saved": {
      "context": "dialog",
      "message": "The file has been saved."
    }
  }
}
```

### 文件: `language/zh-cn.json`

```json
{
  "language": "zh-cn",
  "translations": {
    "common.button.ok": {
      "message": "确定"
    },
    "common.button.cancel": {
      "message": "取消"
    },
    "dialog.file_dialog.open_file": {
      "message": "打开文件"
    },
    "items.count": {
      "message": "1 个项目",
      "plural": {
        "0": "没有项目",
        "1": "1 个项目",
        "2": "{{count}} 个项目"
      }
    }
  }
}
```

### 翻译条目架构

| 字段 | 类型 | 必填 | 描述 |
|-------|------|:---:|------|
| `message` | `String` | ✅ | 默认翻译文本 |
| `context` | `Option<String>` | ❌ | 为相同键的翻译消除歧义 |
| `plural` | `Option<HashMap<u32, String>>` | ❌ | 按数量键区分的复数形式 |

## 3. `tr!()` 宏

`tr!()` 宏提供对全局翻译管理器的编译时访问，支持三种重载模式：

### 基本翻译

```rust
use rust_widgets::tr;

// 初始化全局 i18n 系统
rust_widgets::i18n::init("language/", false).unwrap();

let ok_label = tr!("common.button.ok");
// → "OK"

let cancel_label = tr!("common.button.cancel");
// → "Cancel"
```

### 复数翻译

```rust
let count: u32 = 5;
let label = tr!("items.count", count);
// → "5 items" (使用 count=2 的复数形式)

let zero_label = tr!("items.count", 0);
// → "No items" (使用 count=0 的复数形式)
```

### 上下文感知翻译

```rust
// 相同键，不同上下文
let status_text = tr!("file.saved", "status_bar", 1);
// → "File saved successfully"

let dialog_text = tr!("file.saved", "dialog", 1);
// → "The file has been saved."
```

### 宏展开

```rust
// tr!("key") 展开为:
crate::i18n::translate("key")

// tr!("key", count) 展开为:
crate::i18n::translate_with_context("key", None, count)

// tr!("key", context, count) 展开为:
crate::i18n::translate_with_context("key", Some(context), count)
```

## 4. 复数支持

每个翻译条目中通过整数键定义复数形式：

```json
{
  "notifications.count": {
    "message": "1 notification",
    "plural": {
      "0": "No notifications",
      "1": "1 notification",
      "2": "{{count}} notifications"
    }
  }
}
```

```rust
use rust_widgets::tr;

// 单数
assert_eq!(tr!("notifications.count", 1), "1 notification");

// 复数
assert_eq!(tr!("notifications.count", 5), "5 notifications");

// 零
assert_eq!(tr!("notifications.count", 0), "No notifications");
```

复数解析器将精确的数量匹配到复数键。如果没有匹配的复数形式，则返回默认的 `message`。

## 5. 上下文感知翻译

当同一个翻译键出现在多个 UI 上下文中时，`context` 字段用于消除歧义：

```json
{
  "action.delete": {
    "context": "button",
    "message": "Delete"
  },
  "action.delete": {
    "context": "dialog_title",
    "message": "Delete Confirmation"
  }
}
```

```rust
use rust_widgets::tr;

let button_label = tr!("action.delete", "button", 1);
// → "Delete"

let dialog_title = tr!("action.delete", "dialog_title", 1);
// → "Delete Confirmation"
```

如果请求的上下文与翻译的上下文不匹配，则返回键本身作为回退。

## 6. 全局 i18n 初始化

### 基本初始化

```rust
use rust_widgets::i18n::{self, InitOptions};

let report = i18n::init_with_options(InitOptions {
    translations_dir: "language/".into(),
    default_language: "en".into(),
    diagnostics: true,
    ..Default::default()
});

for error in &report.errors {
    eprintln!("i18n 初始化错误: {}", error);
}
println!("已加载 {} 种语言", report.languages_loaded);
```

### `InitOptions` 和 `InitReport`

```rust
pub struct InitOptions {
    /// 包含翻译 JSON 文件的目录。
    pub translations_dir: String,
    /// 默认语言代码（例如 "en"）。
    pub default_language: String,
    /// 启用诊断日志。
    pub diagnostics: bool,
}

pub struct InitReport {
    /// 成功加载的语言文件数量。
    pub languages_loaded: usize,
    /// 已加载的语言代码列表。
    pub languages: Vec<String>,
    /// 初始化过程中遇到的错误。
    pub errors: Vec<String>,
}
```

### 便捷函数

```rust
use rust_widgets::i18n;

// 使用默认值快速初始化（en，无诊断）
i18n::init("language/", false).unwrap();

// 通过全局管理器翻译
let text = i18n::translate("common.button.ok");

// 通过全局管理器的上下文感知翻译
let text = i18n::translate_with_context("file.saved", Some("status_bar"), 1);

// 检查所有已加载的翻译文件是否有修改
let events = i18n::check_and_reload_all();
```

## 7. 使用 `I18nFileWatcher` 热重载

`I18nFileWatcher` 监视目录中的 JSON 文件变化，并自动重新加载翻译，无需重启应用程序。

### 设置

```rust
use std::path::Path;
use rust_widgets::i18n::{init_with_hot_reload, process_reload_events, InitOptions};

let options = InitOptions {
    translations_dir: "language/".into(),
    default_language: "en".into(),
    diagnostics: true,
};
let watch_dir = Some(Path::new("language/"));

let (report, file_watcher) = init_with_hot_reload(options, watch_dir);

println!("已加载 {} 种语言", report.languages_loaded);
println!("热重载: {}", file_watcher.is_hot_reload_enabled());
```

### 处理重载事件

在应用程序事件循环中，轮询重载事件：

```rust
// 轮询文件变化事件
let events = process_reload_events(file_watcher.receiver());

for event in &events {
    match event {
        ReloadEvent::TranslationReloaded { language, .. } => {
            println!("已重载: {}", language);
        }
        ReloadEvent::ReloadError { language, error } => {
            eprintln!("重载 {} 失败: {}", language, error);
        }
    }
}
```

### 手动触发重载

```rust
// 重载特定语言
manager.reload_translation("en").unwrap();

// 检查所有语言是否有修改
let events = manager.check_and_reload();
for event in &events {
    println!("{:?}", event);
}
```

### 启用/禁用热重载

```rust
// 启用
manager.enable_hot_reload(sender);

// 检查状态
if manager.is_hot_reload_enabled() {
    println!("热重载已激活");
}

// 禁用
manager.disable_hot_reload();
```

## 8. 翻译审计

`audit_keys()` 方法返回所有已加载语言中所有唯一的翻译键，按字母顺序排序。这对于检测缺失翻译非常有用：

```rust
let manager = rust_widgets::i18n::get_manager();
let guard = manager.lock().unwrap();

if let Some(ref mgr) = *guard {
    let all_keys = mgr.audit_keys();
    println!("唯一键总数: {}", all_keys.len());

    for key in &all_keys {
        // 检查键是否在所有语言中都存在
        let en_text = {
            mgr.set_language("en");
            mgr.translate(key)
        };
        let zh_text = {
            mgr.set_language("zh-cn");
            mgr.translate(key)
        };

        // 如果翻译等于键本身，则表示缺失
        if zh_text == *key {
            eprintln!("zh-cn 缺失: {}", key);
        }
    }
}
```

### 覆盖率报告示例

```rust
fn audit_missing_translations(manager: &I18nManager, target_lang: &str) -> Vec<String> {
    let mut missing = Vec::new();
    let current = manager.current_language().clone();

    // 从源语言 (en) 获取所有键

    let keys = manager.audit_keys(); // 需要临时切换语言回来

    // 检查目标语言
    // ...（设置语言，检查每个键）

    missing
}
```

1. 创建新的 JSON 文件：`language/fr.json`
2. 设置 `language` 字段：`"fr"`
3. 为所有键添加翻译：
   ```json
   {
     "language": "fr",
     "translations": {
       "common.button.ok": { "message": "OK" },
       "common.button.cancel": { "message": "Annuler" }
     }
   }
   ```
4. 加载它：`manager.load_translations("language/fr.json")`

## 10. 完整的 i18n 集成示例

```rust
use rust_widgets::i18n::{self, init_with_hot_reload, process_reload_events, InitOptions};
use rust_widgets::tr;
use std::path::Path;

fn main() {
    // 初始化带热重载的 i18n
    let options = InitOptions {
        translations_dir: "language/".into(),
        default_language: "en".into(),
        diagnostics: true,
    };
    let (report, watcher) = init_with_hot_reload(
        options,
        Some(Path::new("language/")),
    );

    println!("已加载 {} 种语言", report.languages_loaded);
    for lang in &report.languages {
        println!("  - {}", lang);
    }

    // 使用翻译字符串构建 UI
    let window_title = tr!("app.title", 1);
    let ok_button = tr!("common.button.ok");
    let cancel_button = tr!("common.button.cancel");

    // 动态复数
    let item_count: u32 = get_item_count();
    let count_label = tr!("items.count", item_count);

    // 上下文感知
    let status_message = tr!("file.saved", "status_bar", 1);

    // 主事件循环
    loop {
        // 每帧处理热重载事件
        let events = process_reload_events(watcher.receiver());
        for event in &events {
            match event {
                ReloadEvent::TranslationReloaded { language, .. } => {
                    println!("[i18n] 语言 {} 已重载", language);
                    // UI 将在下一帧获取新的翻译
                }
                ReloadEvent::ReloadError { language, error } => {
                    eprintln!("[i18n] 重载 {} 失败: {}", language, error);
                }
            }
        }

        // ... 使用翻译后的字符串渲染帧 ...
        std::thread::sleep(std::time::Duration::from_millis(16));
    }
}
```

## 11. 架构总结

```
┌─────────────────────────────────────────────────┐
│                   Application                    │
│  tr!("key") / tr!("key", count) / tr!("k","c",n)│
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│               Global I18nManager                │
│  translate() / translate_with_context()          │
│  load_translations() / reload_translation()      │
│  audit_keys() / set_language()                   │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              I18nFileWatcher                     │
│  watch_directory() / receiver() / sender()       │
│  process_reload_events()                         │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│         language/*.json (Translation Files)       │
│  en.json  │  zh-cn.json  │  zh-tw.json          │
└─────────────────────────────────────────────────┘
```

| 组件 | 角色 |
|-----------|------|
| `I18nManager` | 核心注册表：加载翻译，使用复数/上下文解析键 |
| `tr!()` 宏 | 用于便捷翻译访问的编译时宏 |
| `Translation` 结构体 | `{ context, message, plural }` — 翻译单元 |
| `TranslationFile` 结构体 | `{ language, translations: HashMap<String, Translation> }` |
| `I18nFileWatcher` | 用于热重载的文件系统监视器 |
| `ReloadEvent` | 通知类型：`TranslationReloaded` 或 `ReloadError` |
| `InitOptions` / `InitReport` | 初始化的配置和诊断报告 |
| `language/` 目录 | 包含每种支持语言的 JSON 翻译文件 |
