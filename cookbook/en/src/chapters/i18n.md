# Internationalization (i18n)

rust-widgets provides a full internationalization system with JSON-based
translation files, compile-time macros, pluralization, context-aware translation,
and hot-reload via file system watching.

---

## 1. `I18nManager` — Language Registry

`I18nManager` is the central i18n registry. It loads translations from JSON
files, switches active languages, and resolves translation keys with plural
and context support.

```rust
use rust_widgets::i18n::I18nManager;

let mut manager = I18nManager::new();

// Load translation files
manager.load_translations("language/en.json").unwrap();
manager.load_translations("language/zh-cn.json").unwrap();
manager.load_translations("language/zh-tw.json").unwrap();

// Set active language
manager.set_language("zh-cn");
println!("Active language: {}", manager.current_language());

// Translate a key
let text = manager.translate("common.button.ok");
assert_eq!(text, "确定");  // Chinese
```

## 2. Translation File Format

Translation files are JSON documents with a `language` identifier and a
`translations` map. Each translation entry contains a `message` with optional
`context` and `plural` fields.

### File: `language/en.json`

```json
{
  "language": "en",
  "translations": {
    "common.button.ok": {
      "message": "OK"
    },
    "common.button.cancel": {
      "message": "Cancel"
    },
    "dialog.file_dialog.open_file": {
      "message": "Open File"
    },
    "items.count": {
      "message": "1 item",
      "plural": {
        "0": "No items",
        "1": "1 item",
        "2": "{{count}} items"
      }
    },
    "file.saved": {
      "context": "status_bar",
      "message": "File saved successfully"
    },
    "file.saved": {
      "context": "dialog",
      "message": "The file has been saved."
    }
  }
}
```

### File: `language/zh-cn.json`

```json
{
  "language": "zh-cn",
  "translations": {
    "common.button.ok": {
      "message": "确定"
    },
    "common.button.cancel": {
      "message": "取消"
    },
    "dialog.file_dialog.open_file": {
      "message": "打开文件"
    },
    "items.count": {
      "message": "1 个项目",
      "plural": {
        "0": "没有项目",
        "1": "1 个项目",
        "2": "{{count}} 个项目"
      }
    }
  }
}
```

### Translation Entry Schema

| Field | Type | Required | Description |
|-------|------|:---:|-------------|
| `message` | `String` | ✅ | Default translation text |
| `context` | `Option<String>` | ❌ | Disambiguates same-key translations |
| `plural` | `Option<HashMap<u32, String>>` | ❌ | Plural forms keyed by count |

## 3. The `tr!()` Macro

The `tr!()` macro provides compile-time access to the global translation
manager with three overload patterns:

### Basic Translation

```rust
use rust_widgets::tr;

// Initialize the global i18n system
rust_widgets::i18n::init("language/", false).unwrap();

let ok_label = tr!("common.button.ok");
// → "OK"

let cancel_label = tr!("common.button.cancel");
// → "Cancel"
```

### Pluralized Translation

```rust
let count: u32 = 5;
let label = tr!("items.count", count);
// → "5 items" (uses the plural form for count=2)

let zero_label = tr!("items.count", 0);
// → "No items" (uses the plural form for count=0)
```

### Context-Aware Translation

```rust
// Same key, different contexts
let status_text = tr!("file.saved", "status_bar", 1);
// → "File saved successfully"

let dialog_text = tr!("file.saved", "dialog", 1);
// → "The file has been saved."
```

### Macro Expansion

```rust
// tr!("key") expands to:
crate::i18n::translate("key")

// tr!("key", count) expands to:
crate::i18n::translate_with_context("key", None, count)

// tr!("key", context, count) expands to:
crate::i18n::translate_with_context("key", Some(context), count)
```

## 4. Pluralization Support

Plural forms are defined per translation entry with integer keys:

```json
{
  "notifications.count": {
    "message": "1 notification",
    "plural": {
      "0": "No notifications",
      "1": "1 notification",
      "2": "{{count}} notifications"
    }
  }
}
```

```rust
use rust_widgets::tr;

// Singular
assert_eq!(tr!("notifications.count", 1), "1 notification");

// Plural
assert_eq!(tr!("notifications.count", 5), "5 notifications");

// Zero
assert_eq!(tr!("notifications.count", 0), "No notifications");
```

The plural resolver matches the exact count to a plural key. If no matching
plural form exists, the default `message` is returned.

---

## 5. Context-Aware Translation

When the same translation key appears in multiple UI contexts, the `context`
field disambiguates:

```json
{
  "action.delete": {
    "context": "button",
    "message": "Delete"
  },
  "action.delete": {
    "context": "dialog_title",
    "message": "Delete Confirmation"
  }
}
```

```rust
use rust_widgets::tr;

let button_label = tr!("action.delete", "button", 1);
// → "Delete"

let dialog_title = tr!("action.delete", "dialog_title", 1);
// → "Delete Confirmation"
```

If the requested context does not match the translation's context, the key
itself is returned as fallback.

## 6. Global i18n Initialization

### Basic Initialization

```rust
use rust_widgets::i18n::{self, InitOptions};

let report = i18n::init_with_options(InitOptions {
    translations_dir: "language/".into(),
    default_language: "en".into(),
    diagnostics: true,
    ..Default::default()
});

for error in &report.errors {
    eprintln!("i18n init error: {}", error);
}
println!("Loaded {} languages", report.languages_loaded);
```

### `InitOptions` and `InitReport`

```rust
pub struct InitOptions {
    /// Directory containing translation JSON files.
    pub translations_dir: String,
    /// Default language code (e.g., "en").
    pub default_language: String,
    /// Enable diagnostic logging.
    pub diagnostics: bool,
}

pub struct InitReport {
    /// Number of language files successfully loaded.
    pub languages_loaded: usize,
    /// List of language codes loaded.
    pub languages: Vec<String>,
    /// Errors encountered during initialization.
    pub errors: Vec<String>,
}
```

### Convenience Functions

```rust
use rust_widgets::i18n;

// Simple init with defaults (en, no diagnostics)
i18n::init("language/", false).unwrap();

// Translate via global manager
let text = i18n::translate("common.button.ok");

// Context-aware via global manager
let text = i18n::translate_with_context("file.saved", Some("status_bar"), 1);

// Check all loaded translations for modified files
let events = i18n::check_and_reload_all();
```

## 7. Hot Reload with `I18nFileWatcher`

`I18nFileWatcher` monitors a directory for JSON file changes and automatically
reloads translations without restarting the application.

### Setup

```rust
use std::path::Path;
use rust_widgets::i18n::{init_with_hot_reload, process_reload_events, InitOptions};

let options = InitOptions {
    translations_dir: "language/".into(),
    default_language: "en".into(),
    diagnostics: true,
};
let watch_dir = Some(Path::new("language/"));

let (report, file_watcher) = init_with_hot_reload(options, watch_dir);

println!("Loaded {} languages", report.languages_loaded);
println!("Hot reload: {}", file_watcher.is_hot_reload_enabled());
```

### Processing Reload Events

In the application event loop, poll for reload events:

```rust
// Poll for file change events
let events = process_reload_events(file_watcher.receiver());

for event in &events {
    match event {
        ReloadEvent::TranslationReloaded { language, .. } => {
            println!("Reloaded: {}", language);
        }
        ReloadEvent::ReloadError { language, error } => {
            eprintln!("Failed to reload {}: {}", language, error);
        }
    }
}
```

### Manual Reload Trigger

```rust
// Reload a specific language
manager.reload_translation("en").unwrap();

// Check all languages for modifications
let events = manager.check_and_reload();
for event in &events {
    println!("{:?}", event);
}
```

### Enabling/Disabling Hot Reload

```rust
// Enable
manager.enable_hot_reload(sender);

// Check status
if manager.is_hot_reload_enabled() {
    println!("Hot reload is active");
}

// Disable
manager.disable_hot_reload();
```

## 8. Translation Audit

The `audit_keys()` method returns all unique translation keys across all
loaded languages, sorted alphabetically. This is useful for detecting
missing translations:

```rust
let manager = rust_widgets::i18n::get_manager();
let guard = manager.lock().unwrap();

if let Some(ref mgr) = *guard {
    let all_keys = mgr.audit_keys();
    println!("Total unique keys: {}", all_keys.len());

    for key in &all_keys {
        // Check if key exists in all languages
        let en_text = {
            mgr.set_language("en");
            mgr.translate(key)
        };
        let zh_text = {
            mgr.set_language("zh-cn");
            mgr.translate(key)
        };

        // If translation equals the key itself, it's missing
        if zh_text == *key {
            eprintln!("Missing zh-cn: {}", key);
        }
    }
}
```

### Coverage Report Example

## 10. Complete i18n Integration Example

```rust
use rust_widgets::i18n::{self, init_with_hot_reload, process_reload_events, InitOptions};
use rust_widgets::tr;
use std::path::Path;

fn main() {
    // Initialize i18n with hot reload
    let options = InitOptions {
        translations_dir: "language/".into(),
        default_language: "en".into(),
        diagnostics: true,
    };
    let (report, watcher) = init_with_hot_reload(
        options,
        Some(Path::new("language/")),
    );

    println!("Loaded {} languages", report.languages_loaded);
    for lang in &report.languages {
        println!("  - {}", lang);
    }

    // Build UI with translated strings
    let window_title = tr!("app.title", 1);
    let ok_button = tr!("common.button.ok");
    let cancel_button = tr!("common.button.cancel");

    // Dynamic plural
    let item_count: u32 = get_item_count();
    let count_label = tr!("items.count", item_count);

    // Context-aware
    let status_message = tr!("file.saved", "status_bar", 1);

    // Main event loop
    loop {
        // Process hot reload events each frame
        let events = process_reload_events(watcher.receiver());
        for event in &events {
            match event {
                ReloadEvent::TranslationReloaded { language, .. } => {
                    println!("[i18n] Language {} reloaded", language);
                    // UI will pick up new translations on next frame
                }
                ReloadEvent::ReloadError { language, error } => {
                    eprintln!("[i18n] Failed to reload {}: {}", language, error);
                }
            }
        }

        // ... render frame with translated strings ...
        std::thread::sleep(std::time::Duration::from_millis(16));
    }
}
```

## 11. Architecture Summary

```
┌─────────────────────────────────────────────────┐
│                   Application                    │
│  tr!("key") / tr!("key", count) / tr!("k","c",n)│
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│               Global I18nManager                │
│  translate() / translate_with_context()          │
│  load_translations() / reload_translation()      │
│  audit_keys() / set_language()                   │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              I18nFileWatcher                     │
│  watch_directory() / receiver() / sender()       │
│  process_reload_events()                         │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│         language/*.json (Translation Files)       │
│  en.json  │  zh-cn.json  │  zh-tw.json          │
└─────────────────────────────────────────────────┘
```

| Component | Role |
|-----------|------|
| `I18nManager` | Core registry: loads translations, resolves keys with plural/context |
| `tr!()` macro | Compile-time macro for ergonomic translation access |
| `Translation` struct | `{ context, message, plural }` — the unit of translation |
| `TranslationFile` struct | `{ language, translations: HashMap<String, Translation> }` |
| `I18nFileWatcher` | File system watcher for hot-reload |
| `ReloadEvent` | Notification type: `TranslationReloaded` or `ReloadError` |
| `InitOptions` / `InitReport` | Configuration and diagnostic reporting for initialization |
| `language/` directory | Contains JSON translation files for each supported language |
