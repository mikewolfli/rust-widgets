## 🛠 全部修复清单

### ✅ Fix 1: 移除 BaseWidget::paint() 空函数
- **文件**: `src/widget/base.rs`
- **操作**: 删除 `paint()` 方法及 `RenderContext` import
- **连锁修复**: `src/widget/menu_toolbar/status_bar.rs` — 移除 `self.base.paint(context)` 调用
- **影响**: Draw trait 的 `draw()` 已是官方渲染入口，无行为变化

### ✅ Fix 2: 移除 Draw::request_custom_redraw() 空函数
- **文件**: `src/widget/draw.rs`
- **操作**: 从 Draw trait 中删除整个方法
- **验证**: grep 确认全项目零调用者

### ✅ Fix 3: Platform::as_any() 安全 fallback
- **文件**: `src/platform/contract.rs`
- **操作**: 将 `panic!("as_any not implemented")` 替换为 `&() as &dyn Any` 安全回退
- **原理**: 所有 12 个具体后端均已覆盖，fallback 仅用于第三方实现

### ✅ Fix 4: Window 使用 rect.right() 替代浮点转换
- **文件**: `src/widget/window.rs`
- **操作**: 3 处 `rect.x + rect.width as f32 as i32` → `rect.right()`
- **效果**: 更清晰、更安全、避免 double→i32 精度损失

### ✅ Fix 5: WidgetKind 零孤儿修复
- **文件**: `src/widget/kind.rs` + `src/widget/mod.rs`
- **操作**:
  - `kind.rs`: 为 `Dialog, PopupWindow, ToggleButton, Menu, MenuItem, FreeformShape` 添加 `#[cfg(not(feature = "mini"))]`
  - `mod.rs`: 添加 `pub use base_widgets::frame::Frame;`
- **效果**: 所有 WidgetKind 变体现在有对应 re-export 或 cfg 配对

### ✅ Fix 6: Image 加载能力
- **文件**: `src/widget/image.rs`
- **操作**: 添加 `from_bytes()` 和 `from_file()` → 使用 `crate::image::decoder::decode_to_rgba8()`
- **条件**: `#[cfg(feature = "image")]` — 免费支持 PNG/JPEG/BMP/GIF/WebP

### ✅ Fix 7: 跨平台剪贴板覆盖
- **文件**: `src/platform/clipboard_stubs.rs`
- **操作**: 添加 3 个新模块:
  - `objc2_macos` — NSPasteboard (objc2)
  - `linux` — 内存模拟（无 FFI 依赖）
  - `wasm` — 内存模拟（web-sys Clipboard Promise API 不兼容同步接口）
