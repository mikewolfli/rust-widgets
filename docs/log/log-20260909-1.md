## 本轮修复项

- `CollapsiblePane`：内容区域与 header 分离，child geometry 会同步到指定 content rect，并在 clip 内绘制；pointer 事件在 header 外部才转发给内容 child。
- `PagerPageView`：页面内容使用独立 content rect，非 indicator 区域内绘制与事件转发，当前页身份在移除/切换阶段保持一致。
- `SimpleRegistry`：保留 geometry callback 路径，所有主容器在 draw/event 前对 child 进行几何同步。
- `ActionRouter::bind_shortcut`：失败时会回滚并撤销已注册 shortcut，避免半完成绑定残留。
- `Computed`：文档更新为“dirty 仅表示待重算，listener 仅在真实值变化时触发”；通知测试固定为 invalidate 不立即 emit。
- `EventLoop`：mini 构建下 `pump_once()` 的 host contract 作为单步驱动模式被明确保留，并通过测试覆盖。
- 日志：已清理历史完成率与重复验证记录，保留最终状态单一事实记录。
- `SearchBar`、`CodeEditor`、`MarkdownEditor`：接入共享 `TextSnapshotCommand` 与 `UndoStack`，Ctrl+Z/Ctrl+Y 会真实恢复控件文本。
- `TagInput`：接入完整状态快照历史，undo/redo 同时恢复 tags 与 input buffer。
- `KeySequenceEdit`、`DateEdit`、`TimeEdit`、`DateTimeEdit`：接入专用值快照历史，set/step/录制路径均进入 undo/redo。
- `BaseWidget`：现代 mouse/key/pointer/focus 事件现在映射到公开 signal，不再只有 legacy 事件可达。
- `ShortcutManager`：新增 `handle_event(&Event)`，把 `Event::KeyPress` 转成 `Key`/`Modifiers` 后触发已注册 shortcut。
- `Event`：新增非平台文本输入/IME 事件变体与构造函数。
- cookbook：同步事件枚举、构造函数、`EventHandler` 签名和 BaseWidget 示例。
- macOS objc2：扩展控件 handle kind 增加 `SpinBox`、`ListView`、`ScrollArea`，对应创建函数写入真实 kind。
- iOS：扩展控件 handle kind 增加 `SpinBox`、`ListView`、`ScrollArea`，对应创建函数写入真实 kind；`capabilities()` 显式声明 mobile contract。
- macOS objc2 native bridge：`store_native_view` retain/`remove_native_view` release，新增 parent/subview/frame/hidden/enabled/text setter，接入平台 show/hide/geometry/enabled/text 路径；`menu_add_item` 解析 shortcut 并写入 native menu item + state。
- iOS UIKit bridge：`drain_button_events` 接入 `poll_widget_trigger_event`；ButtonTarget 迁移到 objc2 0.6 `define_class!`；UIKit helper 迁移到 typed API（core-graphics geometry、UIScrollView/UIStackView/UIActivityIndicatorView、UIControlState）。
