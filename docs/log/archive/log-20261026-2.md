## 1. 第 1 章 1.1 渲染管线

### 1.1 G-001 分桶录制借用画刷深拷贝 — 复核：既有形态已覆盖（不改）

实读 `src/render/backend/surface.rs`、`src/render/core/command.rs`、`src/render/backend/paint.rs`：

- `fill_gradient`（`surface.rs:1319`）在非录制路径直接 `backend.fill_gradient(rect, gradient)`，零拷贝；录制路径构造 `Arc<Gradient>`，与 `command.rs:562` 的 `DrawGradient { gradient: Arc<Gradient> }` 同一形态。
- `draw_text`（`surface.rs:1818` 区段）录制路径 `Arc::from(text)`，非录制路径 `backend.draw_text(..., text, ...)` 走借用；`DrawText.text` 是 `Arc<str>`。
- `draw_image`（`surface.rs:2094` 区段）录制路径 `Arc::from(data)`，非录制路径 `backend.draw_image(..., data)` 走借用；`DrawImage.data` 是 `Arc<[u8]>`。

结论：三条录制路径已统一为 Arc 共享句柄，热路径不再深拷贝。剩余「把调用方借用的 `&Gradient`/`&str`/`&[u8]` 变成可保留句柄」的一次复制是**所有权要求**，不是重复深拷贝；要消除它必须改调用方 API 持有 `Arc`，会扩大公开面且收益仅为每条命令一次小复制。按原则 #51「无实测重复则不接入」，本轮不改，记录为复核结论。
