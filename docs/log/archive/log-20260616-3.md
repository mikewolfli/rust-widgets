# Log 20260616-3 — 深度扫描与多轮修复

## Round 1: 扫描与初步修复

### 发现的问题

#### 1. Grid 类型别名缺失 (WidgetKind 零孤儿原则违规)
- `WidgetKind::Grid` (line 77 in `widget/kind.rs`) 存在变体
- `special_widgets/grid.rs` 中 `GridWidget` 已完整实现
- **但 `widget/mod.rs` 缺少 `pub type Grid = GridWidget;`** — 违反规则22 (WidgetKind 零孤儿原则)

#### 2. GridLayout 仅支持统一 stretch (不完整实现)
- `layout/grid.rs` 中的 `GridLayout` 只有 `column_stretch` 和 `row_stretch` 两个统一因子
- 需要支持每列/每行的独立 stretch 因子
- 缺少 `set_column_stretch_for_col` / `set_row_stretch_for_row` / `column_stretches` / `row_stretches` 方法

#### 3. GridLayout `update` 中 cell_height 计算可能有整数除法精度损失
- 使用 `saturating_sub` 但除法仍可能截断导致总高度分配不足

#### 4. 需要补全 Grid widget 的缺失功能
- 暂无 per-column/per-row stretch 设置功能

### Round 1 已修复 ✅

1. **widget/mod.rs** — 添加 `pub type Grid = GridWidget;` ✅
2. **layout/grid.rs** — 重构为 `column_stretches: Vec<u32>` / `row_stretches: Vec<u32>`，添加 per-column/row stretch 方法 + remainder 余数分配算法 ✅

## Round 2: `std::sync::Mutex` → `crate::compat::Mutex` 迁移 + 死代码清理

### 发现的问题

#### 5. `control_backend/custom/mod.rs` 使用 `std::sync::Mutex`
- 应使用 `crate::compat::Mutex` 以支持 mini (no_std) 构建

#### 6. `platform/runtime.rs` 未使用导入
- `PlatformFamily` 和 `StubPlatform` 被导入但从未使用，带有 `#[allow(unused_imports)]`

#### 7. `event/types.rs` 使用 `std::sync::*` 直接导入
- `std::sync::mpsc::{self, TryRecvError}` 和 `std::sync::{Mutex, OnceLock}` 应通过 compat bridge
- 异步任务函数 `schedule_task` / `drain_tasks` 应在 mini 构建中不编译（no threads）

#### 8. `lottie_widget.rs` 多个 `#[allow(dead_code)]` 字段
- `fill_rule`, `line_cap`, `line_join`, `anchor`, `parent`, `opacity` 等字段解析自 JSON 但从未用于渲染

#### 9. `render_engine/embedded.rs` 带 `#[allow(dead_code)]` 的销毁函数
- `destroy_window()` 和 `destroy_button()` 包含真实逻辑但无调用者

### Round 2 已修复 ✅

1. **control_backend/custom/mod.rs** — `use std::sync::Mutex` → `use crate::compat::Mutex` ✅
2. **platform/runtime.rs** — 删除未使用的 `PlatformFamily` 和 `StubPlatform` 导入 ✅
3. **event/types.rs** — 导入改为 `crate::compat::*`，异步任务函数加 `#[cfg(not(feature = "mini"))]` ✅
4. **lottie_widget.rs** — 6 个死代码字段加 `_` 前缀，移除 `#[allow(dead_code)]` ✅
5. **render_engine/embedded.rs** — `destroy_window`/`destroy_button` 加 `_` 前缀替代 `#[allow(dead_code)]` ✅

### Round 2 验证
- `cargo check --lib`: 编译成功，零错误零警告 ✅
