## 3. 逐条实施明细

### 3.1 FM-01（父 crate 接线）— `src/platform/accessibility/types.rs`

- `impl From<WidgetKind> for AccessibleRole`（全量档）：`Form => Group`、`FormSet => TabGroup`（与 `TabWidget | TabBar` 同取向）。
- `impl From<WidgetKind> for A11yRole`（全量档）：`Form => Group`、`FormSet => Tab`（`A11yRole` 无 `TabGroup` 变体）。
- 测试：`test_role_conversion_widgetkind_to_a11yrole` 增两条断言（`K::Form → R::Group`、`K::FormSet → R::Tab`）。
- 依据：`docs/log/log-20261026-1.md` 对 WebFindBar 的必改触点清单；COMP-01 注释「registered, focusable control that assistive technology cannot classify at all」。
- 【✅已完成：Plan第FM-01条】

### 3.2 FM-05（FormSet 聚合 dirty）

- `formset.rs`：新增字段 `last_dirty`、信号 `pub dirty_changed: Signal1<bool>`、方法 `dirty()`（逐页读子 form 的 `dirty` 属性，`read_form_flag`）与 `publish_dirty()`（边沿）；在 `add_page` / `remove_page` / `clear_pages` / `reset_all` 的表单自身变更点调用。
- `capability.rs`：`FORM_SET_PROPERTIES` 增 `dirty`（`Bool`，可读不可写）；`FORM_SET_EVENTS` 增 `dirty_changed`；`default_property_value` 增 `("form_set","dirty") => Bool(false)`。
- `formset.rs::WidgetProperties`：`get` 增 `dirty`、`set` 归入 `ReadOnlyProperty`、`property_names` 增行（顺序与 schema 一致，测试断言该顺序）。
- 测试：`form_set_dirty_aggregates_its_pages`（子 form 先变脏 → 加入 set 发布 `true` 边沿 → `reset_all` 发布 `false` 边沿）；`the_derived_properties_are_read_only` 增 `dirty`。
- 【✅已完成：Plan第FM-05条】

### 3.3 FM-07（值写通道对称）— `form.rs::write_field_value`

- 写入探测改为与读取同序：`text`(String) → `current_text`(String) → `value`(Int → UInt → Float)。
- 后果修复：值在 `current_text` 的可编辑组合框、只接受 Int/UInt `value` 的控件现在可写。
- 测试：`writing_a_value_through_the_form_probes_the_child_contract`（绑定无 text/current_text/value 的控件必须返回 `false`，不得假装写入）。
- 【✅已完成：Plan第FM-07条】

### 3.4 FM-08（逐字段校验 + 聚焦首个错误）

- `form.rs::validate_field(key)`：只跑该字段的 required 规则，随后发布聚合 validity/dirty 边沿（与 `validate` 同规则）。
- `form.rs::focus_first_invalid()`：取第一个「可见且带错」的字段，调 `rust_widgets::widget::runtime::focus_widget`；返回是否成功聚焦。
- 测试：`validate_field_runs_only_the_named_fields_rule`、`focus_first_invalid_moves_focus_to_the_first_broken_field`（断言 `runtime::focused_widget() == Some(first)`）。
- validator 钩子：⚠️ 未实施（见 §4）。
- 【✅已完成：Plan第FM-08条（方法两半）】

### 3.5 FM-09（按 key 导航）

- `formset.rs::goto_page(key)`：换算 index 后复用 `set_current_index`，继承「禁用页拒绝、越界拒绝」语义。
- 测试：`goto_page_activates_by_key_and_shares_the_refusal_rule`。
- 页序重排：⚠️ 未实施（Plan 未定义该能力，见 §4）。
- 【✅已完成：Plan第FM-09条（goto_page）】

### 3.6 FM-10（`show_labels` 布局契约）

- `form.rs::compute_layouts`：Left 模式标签列宽与 `LABEL_GAP` 在隐藏时为 0，标签矩形宽高均 0；Top 模式不预留 `LABEL_ROW_H`。
- `form.rs::field_height`：Left 为 `control.max(label)` + 错误行；Top 为 `label + control + lines`（`label = show_labels ? LABEL_ROW_H : 0`）。
- 实现现在与 `FormFieldLayout::label` 的既有文档（“zero-sized when labels are hidden”）一致，未改文档。
- 测试：`hiding_labels_reclaims_the_label_column_and_row`（两种 label_position）。
- 过程记录：首次实现只归零了标签宽度，测试在高度断言处以 `left: 32, right: 0` 失败；补 `label_height` 后通过（属本轮唯一一次失败，已修复）。
- 【✅已完成：Plan第FM-10条】

### 3.7 FM-11（溢出契约）

- `form.rs` 模块文档新增 `# Overflow`：容器不滚动，`size_hint()` 是字段所需高度，宿主须给足高度或包 `ScrollArea`。
- suite `README.md` 新增 `## Overflow` 同名契约。
- 滚动集成 / `overflows()` 报告 API：⚠️ 未实施（新增公开能力超出 Plan，见 §4）。
- 【✅已完成：Plan第FM-11条（契约文档）】

### 3.8 FM-12（主题语义色 + 语义态）

- `form.rs::Widget::semantic_state()`：`error_count() > 0` 时 `SemanticState::Error`。
- `form.rs::draw`：容器边框 `resolved_semantic_border("form", semantic_state()).or(style.border_color)`；错误/help 文本色 `style::semantic_color(SemanticColor::Error)`，无主题时回退原字面量 `rgba(190,40,40,255)`（与 Badge/Calendar 同款 `Some(..) => themed, None => literal` 阶梯）。
- 测试：`the_form_reports_the_error_meaning_while_a_field_is_in_error`。
