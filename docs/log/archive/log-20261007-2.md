| N-M-01 | JPEG IDCT 扩宽后，熵解码产生的 DC predictor 仍可能溢出，去量化乘法仍在 `i32` 中溢出。DC 累加和系数去量化现在使用 checked 运算并返回明确错误；IDCT 两阶段累加扩为 `i128`。新增含 16-bit DQT、多个 DC block 的完整解码回归测试，验证超界输入被拒绝。 |
| N-M-02 | PDF 图像载荷长度不匹配时虽然已告警，仍会截断/补零并输出错误图像。现在严格校验 RGB/RGBA/灰度长度与尺寸乘法；无法匹配时记录错误并拒绝写入该图像。新增错误载荷拒绝测试，合法 RGB/RGBA 路径保留。 |
| N-B-02 | 数字选择器使用饱和运算避免 panic，却改变了全 `i64` 范围的 wrap/snap 结果。范围、偏移、步进及滚动运算改用 `i128` 中间值，覆盖整个含端点范围；`u64` 行数仍按 API 上限饱和。扩充极值断言，验证 `0 → 1`、`i64::MIN → i64::MAX` 等 wrap 行为。 |
| N-WEB-01 | HTTP 请求进行中时，`file://`、HTML/data 文档、历史前进/后退及 reload 未使旧请求失效，旧结果可能覆盖新页面。所有被接受的新导航/文档加载现在丢弃 pending receiver 并递增 generation；新增 `web-http` 特性测试逐项验证旧结果不改变新页面状态。 |
| N-T-11 | Wayland 脚本仅用字符串前缀校验调用方提供的运行目录，然后对该路径执行递归删除，`..` 可逃出前缀目录。现在该变量仅作为父目录；脚本通过 `mktemp -d` 创建本轮专属私有运行目录，只清理自己创建的目录，并拒绝相对父路径。 |
| N-T-10 | `mktemp tests/...XXXXXX.rs` 在 BSD/macOS 下不能保证随机生成文件名。现在先用末尾 `XXXXXX` 创建唯一临时文件，再重命名为 `.rs`，并在 EXIT trap 中清理两种文件名。实跑生成器通过。 |
