## 0. 结论

| 目标 | 状态 | 一句话 |
|---|---|---|
| 缓冲有稳定身份 | ✅ | 每个 `EditorBufferSlot` 带 `id: u64`，由文档的 `next_id` 单调分配，关闭后永不复用 |
| 快照按 id 保存 | ✅ | `buffer_views` 从 `Vec<BufferViewState>` 改为 `BTreeMap<u64, BufferViewState>` |
| 自愈 O(1) 快路径 | ✅ | 文档 `generation` 在开/关缓冲时 +1；`sync_with_document` 先比一个整数 |
| 已关闭缓冲的快照被回收 | ✅ | `reconcile_active_buffer` 按现有 id 集合 `retain` |
| 重开不继承旧快照 | ✅ | 新缓冲拿新 id，快照从 `Default` 开始 |

## 1. 为什么按下标会错

两个视图共享同一份缓冲列表。视图 A 关闭了位于视图 B 活动缓冲**之前**的标签时：

- 视图 B 的 `active_buffer: usize` 从 `2` 变成 `1`（同一个缓冲，位置变了）；
- 旧的 `buffer_views: Vec<BufferViewState>` 也是按下标存的，`buffer_views[2]` 属于 B 的缓冲；
- B 一旦重定位到位置 1，就会读到**别人的**快照 —— caret、scroll、folds 全部贴错。

根因是“位置”同时被当成身份与索引。修法是把身份从位置里拆出来。

### 2.2 文档（`editor/document.rs`）

`CodeEditorDocument` 新增两个共享计数器：

- `next_id: Rc<Cell<u64>>` —— 单调分配，关闭不回收，`new()` 的首个缓冲 id 为 1；
- `generation: Rc<Cell<u64>>` —— `push_buffer` / `remove_buffer` 成功时 +1。

新增 crate 内部访问器：

- `buffer_id(index) -> Option<u64>`
- `index_of(id) -> Option<usize>`
- `buffer_ids() -> Vec<u64>`（按标签顺序、id 递增，因此可二分）
- `generation() -> u64`

### 2.3 视图（`editor.rs` / `editor/tabs.rs`）

字段：

```rust
active_buffer_id: u64,                    // 权威身份
active_index: usize,                      // 缓存位置（公开 API 与关闭回退用）
seen_generation: u64,                     // 上次对齐的文档 generation
buffer_views: BTreeMap<u64, BufferViewState>,
```

- `save_active_view`：`buffer_views.insert(self.active_buffer_id, view)`。
- `after_buffer_switch(index)`：`id = buffer_id(index)`，从 map 取快照（缺失则 `Default`）。
- `open_buffer`：`push_buffer` 后给新 id 插入默认快照，记录 `seen_generation`，再激活。
- `activate_buffer(index)`：位置→id；id 相同则只刷新 `active_index` 并返回 `false`；否则存出旧视图、
  重指向 `model`/`undo_stack`、更新 `seen_generation`、恢复新视图。
- `close_buffer(index)`：
  1. 位置→`closed_id`；非活动时先 `save_active_view()`（按 id 存，不会被移除影响）；
  2. `document.remove_buffer(index)`；
  3. `buffer_views.remove(&closed_id)`；刷新 `seen_generation`；
  4. `reconcile_active_buffer()`：活动缓冲仍在则只更新位置，被关掉则重定位。
- `active_buffer()`：`index_of(active_buffer_id)`，查不到时用缓存位置钳制。

### 2.4 自愈（`editor/document.rs`）

```rust
pub fn sync_with_document(&mut self) -> bool {
    if self.seen_generation == self.document.generation() { return false; }
    self.seen_generation = self.document.generation();
    self.reconcile_active_buffer()
}
```

`reconcile_active_buffer`（`pub(super)`，关闭路径也用它）：

1. 用 `buffer_ids()` 二分 `retain` 掉已关闭缓冲的快照；
2. `index_of(active_id)`；
3. 找不到（活动缓冲被别的视图关了）→ 取 `active_index.min(count-1)`，即它原来占据的位置；
4. 只有 id 变化才重指向 `model`/`undo_stack` 并 `after_buffer_switch`（发出切换信号）；
5. 返回“活动缓冲是否变化”。

## 3. 语义（比上一轮更准确）

| 场景 | 之前 | 现在 |
|---|---|---|
| 别的视图关闭了本视图**之前**的标签 | 本视图位置变、且可能读到邻座快照 | 位置变；caret/scroll/folds 仍属于同一缓冲；`sync_with_document()` 返回 `false` |
| 别的视图关闭了本视图的**活动**缓冲 | 重定位 | 重定位到原位置上的后续缓冲（或末尾），返回 `true` |
| 关闭后重新打开 | — | 新 id、新默认快照，不继承旧 caret |
| 每帧自检成本 | 每次都遍历槽位 | 一次整数比较（generation 未变） |

公开 API 形状不变（`active_buffer()` 仍是位置；身份是内部细节）。

## 7. 公开稳定 id API（2026-10-30）

§2 把身份做成了内部实现；本节按宿主需求把它暴露出去。

```rust
impl CodeEditor {
    pub fn active_buffer_id(&self) -> u64;
    pub fn buffer_ids(&self) -> Vec<u64>;
    pub fn activate_buffer_id(&mut self, id: u64) -> bool;
    pub fn close_buffer_id(&mut self, id: u64) -> bool;
}
```

- `active_buffer_id` 返回 `active_buffer_id` 字段（权威身份，不随关闭其它标签变化）。
- `buffer_ids` 委托 `CodeEditorDocument::buffer_ids()`，顺序与 `buffers()` / `buffer_summaries()` 一致
  （按标签顺序；id 递增但不连续）。
- `activate_buffer_id` 用 `index_of(id)` 解析位置后转调 `activate_buffer(index)`：
  - id 已关闭 → `None` → 返回 `false`，不改变当前视图；
  - id 就是当前缓冲 → `activate_buffer` 返回 `false`（只刷新缓存位置）；
  - 否则切到该缓冲并恢复它自己的 caret/scroll/folds。
- `close_buffer_id` 用 `index_of(id)` 解析位置后转调 `close_buffer(index)`：
  - id 不存在 → `false`，不改变任何状态；
  - 最后一个缓冲 → 与位置形态一致，清空文本、保留缓冲与 id；
  - 关闭活动缓冲 → 重定位到接替位置的标签；关闭非活动缓冲 → 当前视图不变。
- 位置形态的 `active_buffer()` / `activate_buffer(index)` / `close_buffer(index)` 保留不变，两套入口并存。

新增用例（`tests_batch8.rs`，共 5 条）：

- `stable_ids_survive_a_close_and_are_the_identity`：关闭 0 号缓冲后，`buffer_ids()` 去掉旧 id、
  `active_buffer_id()` 不变、`active_buffer()` 由 2 变 1；关闭的 id 无法激活，存活 id 可以，重复激活返回
  `false`。
- `an_id_identifies_the_same_buffer_in_both_views`：两个视图的 `buffer_ids()` 一致，一个视图拿到的 id
  在另一个视图里激活到同一个缓冲。
- `close_buffer_id_closes_the_named_buffer`：按 id 关闭非活动缓冲后 id 集合、文本、活动 id 均正确；
  已关闭的 id 与从未存在的 id 都返回 `false`。
- `close_buffer_id_of_the_active_buffer_rehomes`：按 id 关闭活动缓冲后重定位到幸存缓冲，文本正确。
- `close_buffer_id_of_the_last_buffer_empties_it`：最后一个缓冲被清空而不是删除，文档与 id 保留。
