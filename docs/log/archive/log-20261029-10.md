## 1. 结构调整（为什么必须动模型）

上一轮的 `EditorModel` 同时装了四类东西：一个缓冲的文本、**缓冲列表**、**活动缓冲下标**、**折叠**。
其中“活动缓冲”与“折叠”是视图状态，一旦两个视图共享模型就必然打架。本轮按“一类状态一个归属”拆开：

| 状态 | 归属 | 数据结构 |
|---|---|---|
| 一个缓冲的文本索引、镜像、保存点、行尾 | 缓冲 | `EditorModel`（`buffer.rs:31`） |
| 缓冲集、标题、语言覆盖、每个缓冲的 undo 栈 | 文档 | `CodeEditorDocument::slots`（`editor/document.rs:33`、`buffer.rs:585`） |
| revision | 文档 | `Rc<Cell<u64>>` |
| 活动缓冲、caret、selection、scroll、折叠 | 视图 | `CodeEditor`（`editor.rs:488`、`:311`、`:493`） |

关键点：**视图的 `model` 字段指向“当前缓冲”的 `Rc<RefCell<EditorModel>>`**，所以既有的
`self.model.borrow()` 调用面（≈300 处）无需改写；切缓冲只换指针。

## 2. 逐项改动

### 2.1 模型瘦身（`buffer.rs`）

- `EditorModel` 删去 `all_buffers` / `active_tab` / `folds` / `hidden_ranges`，以及
  `apply_tab_switch` / `persist_active` / `load_buffer` / `set_text_owned`、
  `is_hidden` / `fold_at` / `folded_line_count` / `normalize_folds` / `set_folds` / `visible_lines`。
- `EditorModel::new()` 现在只建一个空缓冲的文本索引，不再顺带建 `untitled` 槽位。
- `set_text` / `splice_with_range` 不再调用 `normalize_folds`（折叠已不在模型里）。
- 新增 `EditorBufferSlot { title, language, model: SharedModel, history: Rc<RefCell<UndoStack>> }`
  （`buffer.rs:585`），手写 `Debug`（只打印标题与语言；`UndoStack` 没有 `Debug`，而打印正文既是
  巨型输出也是隐私问题）。

### 2.2 文档句柄（`editor/document.rs`）

- `CodeEditorDocument` 改为 `{ slots: Rc<RefCell<Vec<EditorBufferSlot>>>, revision: Rc<Cell<u64>> }`。
- 公开面保持兼容：`new` / `text` / `revision` / `set_text`。
  - `text()` / `set_text()` 作用于**第一个缓冲**（句柄没有“活动缓冲”概念，那是视图状态），文档写明。
- crate 内部访问器：`buffer_count`、`slot_model`、`slot_history`、`push_buffer`、`remove_buffer`
  （拒绝删最后一个）、`set_history_limit`、`buffer_snapshots`、`buffer_summaries`、`title_at`、
  `set_title_at`、`language_at`、`set_language_at`。
- `slot_model` / `slot_history` 在越界时 `expect`，并在文档里写明不变式：文档永远至少一个缓冲
  （构造即有一个，删除路径拒绝清空），所以越界是调用方 bug，而不是宿主能造出来的状态。

### 2.3 视图（`editor.rs` / `editor/tabs.rs` / `editor/folding.rs`）

- 新字段 `document: CodeEditorDocument`、`active_buffer: usize`、`folds`、`hidden_ranges`；
  `undo_stack` 改为 `Rc<RefCell<UndoStack>>`；删除 `buffer_histories`。
- `build()` 用一个新文档初始化：`model`/`undo_stack` 取自槽位 0，`revision` 取自文档。
- `buffers()` / `buffer_summaries()` 改为读文档槽位（不再 clone 每个缓冲的正文）。
- `open_buffer` 向文档追加槽位，`buffer_views` 同步追加，然后激活。
- `activate_buffer` / `activate_buffer_untracked`：保存本视图的旧缓冲视图 → 记 `active_buffer` →
  重指向 `model` / `undo_stack` → `after_buffer_switch` 恢复 caret/scroll/folds。切换**不再**交换
  历史栈（历史本来就在缓冲上）。
- `close_buffer`：删视图快照 → 删文档槽位 → 重算 `next_active` → 重指向 → `after_buffer_switch`。
- `after_buffer_switch` 额外按新缓冲行数重算 `DocumentScale`（大文件降级级别随缓冲走；这是从
  “只在 `set_text` 时算”修正为“切换时也算”）。
- 折叠方法全部改为读写 `self.folds`；`after_fold_change` 不再手动 `normalize_folds`，由
  `refresh_derived_state` 统一做（它本来就处理行数变化）。
- `refresh_derived_state_after` 第一件事是 `self.normalize_folds()`，然后从 `self.folds` 重建
  `folded_lines` 缓存。

### 2.4 行投影（`editor/rows.rs`）

- `visible_document_lines` 从 `model.visible_lines()` 改为 `self.visible_lines()`。
- 增量重建前缀表时，循环持有 `&mut self.visual_row_prefix`，不能调用 `&self` 的 `is_hidden`；
  改为先克隆合并区间（几对）并用局部闭包查询。复杂度仍是 `O(log folds)`。

### 2.5 undo 调用面

- `self.undo_stack.push/undo/redo/clear` → `borrow_mut()`；`can_undo/can_redo/undo_count` → `borrow()`。
  命令本身只写 `Rc<RefCell<String>>` 镜像，不回调编辑器，所以借用不会重入。
- `set_undo_limit` / `with_document` 对所有缓冲的栈生效（文档写明“两个视图不同上限时后设置者生效”）。

### 2.6 跨视图缓冲增删的自愈

- 新增 `pub fn sync_with_document(&mut self) -> bool`（`editor/document.rs:290`）：
  按当前槽位数量钳制 `active_buffer`，若指针不一致则重指向并 `after_buffer_switch`。
- `Draw::draw`（`render.rs`）与 `EventHandler::handle_event`（`editor/events.rs`）入口各调用一次。
- 限制（写进方法文档与反馈 §9）：另一视图关闭缓冲导致下标移位时，本视图按**下标**对齐的
  caret/scroll 快照可能贴到相邻缓冲；`sync_with_document` 修正的是活动选择，不重建快照。

## 3. 用例

`src/widget/special_widgets/code_editor/tests_batch8.rs` 新增 4 条：

- `two_views_can_show_different_buffers_of_one_document`：视图 A 开第二个缓冲后，A 在 1、B 仍在 0，
  文本各自正确，且缓冲集共享。
- `views_share_the_undo_history_of_a_buffer`：A 键入，B 能 `undo()`，A 的文本随之回退。
- `views_keep_independent_folds`：A `fold(1,2)` 后 `is_line_hidden(2)`，B 仍可见且 `fold_regions()` 为空。
- `closing_a_buffer_rehomes_the_other_view`：A 关闭缓冲，B `sync_with_document()` 后回到 0 号缓冲。

`src/widget/special_widgets/code_editor/tests.rs` 新增 1 条：

- `closing_an_earlier_tab_keeps_the_active_cursor_and_text`：关闭**活动缓冲之前**的标签时，活动标签的
  caret 快照必须随下标一起下移（暴露了一个真实排序错误：先删快照再存视图，会把 caret 写进邻座）。

转移（不是删除）的两组模型测试：

- 折叠的“只隐藏内部行 / 嵌套折叠 / 文档缩短后钳制”三条断言 → `editor/folding.rs` 的测试模块
  （通过 `CodeEditor` 断言，因为折叠已不在模型上）。
- 切标签“保留出栈文本 / 非法下标 no-op” → `editor/tabs.rs` 的测试模块
  （`switching_buffers_persists_the_outgoing_text`、`activating_an_unknown_buffer_is_a_noop`）。
