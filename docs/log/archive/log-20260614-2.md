## 第1轮发现与修复

### 1. App模块封装完善

**发现**: `App` 结构体没有集成 `AppLifecycle` 生命周期管理器，缺少异步运行方法

**修复**:
- 在 `App` 中集成 `AppLifecycle` 管理器字段
- 添加 `lifecycle()` / `lifecycle_mut()` 方法访问生命周期
- 在 `init()` 中自动转换到 `Foreground` 状态
- 在 `quit()` 中自动转换到 `Terminating` 状态

**文件**: `src/app/app_core.rs`

### 2. AppConfig 扩展

**发现**: `AppConfig` 缺少版本号和 accessibility 开关

**修复**:
- 新增 `version: String` 字段和 `with_version()` 方法
- 新增 `enable_accessibility: bool` 字段和 `with_accessibility()` 方法
- 添加 `config_mut()` 方法获取可变引用

**文件**: `src/app/app_core.rs`

### 3. `run_async` 方法实现

**发现**: App 只支持同步 `run()` 阻塞事件循环，无法在非阻塞模式下使用

**修复**:
- 添加 `run_async()` 方法，使用 `std::thread::spawn` 在后台线程运行事件循环
- 返回 `JoinHandle<()>` 供调用者等待或分离

**文件**: `src/app/app_core.rs`

### 4. Layout trait 默认方法优化

**发现**: `Layout::has_child()` 和 `Layout::clear()` 默认实现输出 `log::warn!` 警告，造成日志噪声

**修复**:
- `has_child()`: 移除了 `log::warn!` 调用，直接返回 `false`
- `clear()`: 移除了 `log::warn!` 调用，改为空操作

**文件**: `src/layout/mod.rs`

### 5. 性能监控增强

**发现**: 项目已有 `UpdateBatcher` 和 `DirtyRegionTracker`，但缺少便捷的帧率监控助手

**修复**:
- 新增 `src/performance/frame_timer.rs` 文件
- `FrameTimer` 结构体，基于滑动窗口(默认60帧)计算 FPS 和帧耗时
- 方法: `new()`, `with_window_size()`, `tick()`, `average_fps()`, `frame_time_ms()`, `reset()`
- 8 个单元测试全部通过

**文件**: `src/performance/frame_timer.rs`, `src/performance/mod.rs`
