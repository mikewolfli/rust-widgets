## 5. 事实核对与本轮判断记录（原则 #2 / #4 / #5）

1. **`AnimationClock` 不是零调用方**：`EventLoop::drive_default_animation_clock`（公开方法）经 `advance_default_animation_clock` 到达它，因此未按计划与 `TransitionManager` 一并降为测试面；只把真正无入口、无消费者的 `TransitionManager`/`TransitionRule` 降级。
2. **C2-D0 的“消费即止”在现有 API 上无法用返回值表达**：`Widget::handle_event` 返回 `()`，`dispatch_event` 的 `bool` 表示“找到了控件”，不是“消费了”。因此引入 `claim_wheel()` 线程局部声明（与 legacy 通路的 `take_consumed` 同形），由容器在真正移动后置位；这是计划意图（“消费即止、到边界继续”）在现有签名下唯一可验证的实现，且不需要改任何控件的 `handle_event` 签名。
3. **PL2-01 的“移动通知”在两个后端无数据源**：xdg-shell 无绝对位置事件、orbclient 无 Move 变体。按 #37 不硬编码假装值，故不做。
