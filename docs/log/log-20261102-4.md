## 2. 4.0.0 变更说明（写入 CHANGELOG）

- **配合 rustage 重构**：命令表、统一行滚动、逐控件焦点订阅是该重构目标使用的 API 面。
- RW-44：新增 746 条 `set_*` 命令；`PROGRAMMATIC_ONLY_SETTERS` 777 条具名账；
  `command` 未命中名字改交 `default_command`（属性存在时 `UnknownCommand` → `OutOfRange`，
  这是本轮唯一的行为变化，已在 changelog 的 Migration 段落写明）。
- RW-58：`ScrollableRows` + 31 个注册行容器 + `SuggestionPopup` companion；
  `scroll_row` 属性与 `WidgetHandle::scroll_row/set_scroll_row`。
- RW-63：`on_focus_gained/on_focus_lost` 与 `subscriber_count` 基事件回退。
- 性能：`invoke_command` 命令查找改为哈希索引。
