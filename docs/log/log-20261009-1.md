## 1. 媒体、PDF 与设计器

### D08-M-01 / D08-M-02 · normalize 契约

`src/audio/normalize.rs`：

- `normalize` 改为返回 `Result<(), NormalizationError>`。目标必须先通过有限性与 `0.0..=1.0`
  区间校验，否则返回 `NonFiniteTarget` / `TargetOutOfRange` 且**不改动任何采样**。
- 去除 `.min(10.0)` 的隐藏增益上限：`Peak(level)` 现在把峰值精确驱动到 `level`，
  `Rms(level)` 把 RMS 精确驱动到 `level`，兑现接口说明的“reaches this level”。
- 新增 `NormalizationError` 类型（`Display`/`Error`）并在 `src/audio/mod.rs` 重导出。
- 回归：`peak_reaches_requested_level_without_hidden_cap`、`rms_reaches_requested_level_without_hidden_cap`、
  `non_finite_target_is_rejected_without_touching_samples`、`out_of_range_target_is_rejected`、
  `zero_and_one_targets_are_valid`。

### D08-M-03 · WAV 编码/解码契约对称

`src/audio/encoder.rs`：`encode_wav` 在写出头之前校验采样数是声道数的整数倍，残缺尾帧显式
返回错误（消息含 “whole number of frames”），与 `decoder.rs` 的整帧校验对称。

- 回归：`encode_wav_rejects_incomplete_final_frame`、`encoded_wav_roundtrips_through_the_library_decoder`
  （mono/stereo/4 声道编码后由库自身解码器成功还原）。

### D08-PDF-01 · ComboBox 单选

`src/pdf/form.rs`：`select_option` 把 `ComboBox` 与 `Radio`/`Checkbox` 一并视为单选：第二次
选择替换第一次并同步 `value`；`ListBox` 保持多选语义。

- 回归：`combo_box_keeps_a_single_selection_and_exports_it`。

### D08-PDF-02 · 取消选择后的导出

- `deselect_option` 现在同步 `value`：被取消的选项正是当前 `value` 时清空（单选类型）或采用
  最后一个剩余选择（ListBox）；取消其它索引不清掉有效选择。
- `to_pdf_form_field` 的 Checkbox/Radio `checked` 改由 `selected_indices` 决定，不再被残留
  `value` 误判为选中。
- 回归：`deselecting_a_choice_clears_the_checkbox_value`、`checkbox_export_is_driven_by_selection_not_stale_value`。

### D08-PDF-03 · 必填选择字段判据

`Form::validate` 改为按 `FieldType` 判定：ListBox 由合法选中索引满足，ComboBox 由合法选择或
非空 value 满足；越界索引不算有效值。新增 `FormField::has_a_value_for_its_kind`。

- 回归：`required_choice_fields_validate_on_selection`。

### D08-PDF-04 · 密码遮罩按字符计数

`get_display_value` 用 `value.chars().count()`，与 `set_value` 的字符口径一致。

- 回归：`password_mask_counts_characters`（中文/多字节）。

### D08-J-01 · 设计器拒绝非法函数名

`src/designer/generator.rs`：新增 `validate_function_name`（标识符 + 保留字检查）并在 `generate`
入口调用一次，覆盖 default/stripped/空输出三条路径；非法名返回 `Err` 而非产出不可编译源码。

- 回归：`an_invalid_function_name_is_refused`、`function_name_validation_accepts_identifiers_only`。

## 2. 视图差分与布局

### D08-V-01 · 类型替换的父节点

`src/view/diff.rs`：`diff_children` 递归 `diff_node` 时把容器 id（`parent_id`）作为子节点的父，
不再传子节点自身 id。修复 `window→label(key=a)` 更新为 `button(key=a)` 时产生
`Replace { parent: label_id }` 的逻辑孤儿。

- 回归（`src/view/apply.rs`）：`a_type_change_on_a_keyed_child_replaces_it_in_place`
  ——diff→apply 后窗口仍有唯一子节点且为 `button`。

### D08-V-02 · 三节点循环重排

`diff_children` 改用以最长递增子序列（`children_to_move`）判定需要移动的节点，逐个移动到
其目标索引；`[a,b,c]→[c,a,b]` 现在应用到正确顺序。

- 回归：`a_three_node_cyclic_reorder_reaches_the_declared_order`（应用后顺序为 `c,a,b` 且身份保留）。

### D08-V-03 · keyless 前插不抢占 keyed

`diff_children` 改为两趟：先按 key 匹配（保留 keyed 身份），再做 keyless 位置匹配，避免新建
无 key 节点吃掉即将被 keyed 节点使用的旧节点。

- 回归：`a_keyless_insert_does_not_steal_a_keyed_sibling`（应用后 key `a` 唯一且保留原 id）。

### D08-L-01 · FlowLayout 负间距误判换行

`src/layout/flow.rs`：布局过程记录每行起始索引（`line_starts`），`apply_alignment` 据此分行，
不再用 `major <= origin` 的坐标启发式；负间距下单行不再被拆分为两行。Horizontal 与 Vertical 两路
同步修复。

- 回归：`negative_spacing_with_space_between_keeps_one_line`、
  `negative_spacing_with_space_between_keeps_one_column`、`wrapping_still_splits_lines_with_negative_spacing`。

### D08-L-02 · AspectRatioLayout 亚像素与无限比例

`src/layout/aspect_ratio.rs`：`new`/`set_aspect_ratio`/test helper 要求比例 `is_finite() && > 0.0`；
`compute_child_rect` 对正的亚像素 extent 保留最小 1 像素（空父区域仍为 0）。

- 回归：`a_positive_sub_pixel_extent_keeps_one_pixel`、`an_empty_parent_still_yields_a_zero_sized_child`、
  `non_finite_ratios_are_rejected`。
