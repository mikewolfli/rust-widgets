# Work logs

Per-day evidence logs: what changed in a round, which gate was run, and the
command output that proves it. A log is written **as the work happens**; a plan
that cites a log must cite one that exists (principle #105 — a dead reference
is a claim with no evidence behind it).

## Layout

- `docs/log/log-YYYYMMDD-N.md` — the **active** logs, newest last.
- `docs/log/archive/` — logs whose plan has finished. They stay readable; only
  their location changes. Every file there is listed below, and
  `bash tools/check_log_archive_has_index.sh` fails when one is not.
- `docs/log/assets/` — images a log embeds.
