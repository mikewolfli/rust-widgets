## 1. 逐条实施

### FM-02 → 方案 B：把「Enter 由谁发起」写成契约

- `form.rs` 模块文档新增 `# Enter submits through the focused field`：键盘路由只投递给焦点控件、Form 不可聚焦、`handle_event` 的 `KeyPress` 臂是**容器转发路径**而非独立表单的收键声明。
- `README.md` 新增 `## Enter submits through the field`：宿主把字段的 `return_pressed` 绑到 `Form::submit`；`FormSet` 自动转发。
- 未改行为、未新增 API。
- 【✅已完成：Plan第FM-02条】

### FM-03 → 方案 C：转发后事件驱动重同步

- `Form` 新增 `observed: Vec<(String, Option<String>)>`（**边沿检测**，非权威存储）、`resync_derived()`、`sync_observed()`、`note_observed()`。
- `handle_event` 在把事件转发给字段之后调用 `resync_derived()`：值变化发 `field_changed(key)`，随后发布 `dirty_changed`/`validity_changed` 边沿。
- `add_field` / `remove_field` / `clear_fields` 维护快照；`set_value_of` 调 `note_observed` 防止重复上报；`reset` 写回基线后 `sync_observed`。
- 测试：`a_direct_child_edit_publishes_its_edges_on_the_next_event`（直接写子控件 `text` → 不立即发事件 → 下一次转发事件后 `field_changed("name")` + `dirty_changed(true)`）。
- 限制（已写入 README）：宿主绕过容器直接写子控件后需调 `refresh()`。
- 【✅已完成：Plan第FM-03条】

### FM-06 → 方案 B：容器向下传播 enabled

- `Form` 的 `WidgetProperties::set` 增加 `"enabled"` 臂：写 base 后对每个绑定字段 `set_widget_enabled`。
- `FormSet` 同样增加 `"enabled"` 臂，并在 `apply_page_visibility` 中对每个页面 form 同步 `enabled`。
- 效果：子控件自身 `is_enabled` 变 false → `wants_keyboard_focus` 自然把它们移出 tab 序与点击焦点。
- 测试：`disabling_the_container_disables_the_fields_it_hosts`（Form 与 FormSet 两条路径，读子控件 `enabled` 属性断言）。
- 记录：运行时「有效 enabled」祖先求值**未实施**（`Widget::parent()` 存 own id、运行时表用 registry id，属 RTS-01 同族），如需全局继承应单独立项。
- 【✅已完成：Plan第FM-06条】

### FM-08 → 方案 A：校验器挂在 Form（不进 FormField）

- `Form` 新增 `validators: BTreeMap<String, FieldValidator>`（`type FieldValidator = Rc<dyn Fn(&str) -> Option<String>>`），`FormField` 保持 `PartialEq/Eq` 不变。
- 新增 `set_field_validator(key, f)` / `clear_field_validator(key)`（未知 key 返回 false）。
- `validate` / `validate_field` 顺序：required → validator；结果写入 `validation_error`（`external_error` 仍优先显示）。
- 触发时机：仅 `validate*`（提交/显式），未加自动重校验属性。
- 测试：`a_host_rule_runs_after_the_required_check`。
- 【✅已完成：Plan第FM-08条】

### FM-09 → 方案 A：`move_page(key, index)`

- 越界 index 拒绝（不钳制）；未知 key 返回 false；按 key 记录活动页，移动后重算 `current`，不改变可见页。
- 不发新事件（宿主自己发起的移动）。
- 测试：`move_page_reorders_and_keeps_the_active_page`。
- 【✅已完成：Plan第FM-09条】

### FM-11 → 方案 A + `overflows()`

- 新增只读 `overflows() -> bool`（`size_hint().height > geometry().height`）；不新增属性、不做自带滚动。
- 测试：`overflows_reports_a_form_that_needs_more_height`。
- 【✅已完成：Plan第FM-11条】
