## 2. 父 crate 的必要接线（最小改动）

1. `src/widget/kind.rs` 新增两个 **external** 变体：

   ```rust
   // kind-role: external: registered by the `rust-widgets-suites` package (the `form_widgets`
   // group), so this package's factory does not carry a constructor for it.
   Form,
   FormSet,
   ```

   同步补 `css_name` 臂，并把 `FormSet` 加入 `wants_keyboard_focus` 的正面列表（方向键翻页、Enter
   提交）。未加入 `accepts_ime_input`（表单容器不直接接收文本）。
2. `src/control_backend/routing.rs` 的穷尽 `match` 增加两臂（仍为 `CustomRequired`，库自绘）。
3. `examples/widget_reachability.rs` 的 `all_kinds` / `exhaustive` 增加两个变体，计数 228 → 230。
4. 文档计数 228 → 230（22 个文档，含 README、cookbook 三语、codemap、gallery、control.md）。
5. `docs/plans/codemap.md` 的 WidgetKind→Module 映射新增两行（指向 suite crate 的真实路径）。
6. `tools/generate_platform_capability_matrix.py`：总数行改为「228 parent-registered kinds」，
   并**动态解析** `kind-role: external` 变体，生成
   `Registered by optional packages (outside this matrix): WebFindBar, Form, FormSet`。
   这样矩阵不把外部控件算进父工厂行数，同时枚举总数与文档计数不会漂移。

## 3. `Form` 的五面

### 3.1 属性（21 + 共享 4）

`title` / `show_title` / `label_position`(left|top) / `label_width` / `row_height` / `row_spacing` /
`column_spacing` / `content_padding` / `columns` / `required_mark` / `required_error` /
`show_labels` / `show_errors` / `show_buttons` / `submit_label` / `reset_label` / `button_width`，
派生只读 `field_count` / `valid` / `error_count` / `dirty`，以及 `enabled` / `visible` / `tooltip` /
`geometry`。每条都有 `PropertySchema` 与 `get`/`set`/`property_names` 实现。

### 3.2 方法

字段模型：`fields` / `field` / `field_mut` / `field_count` / `field_keys` / `add_field` /
`add_field_with_widget` / `remove_field` / `clear_fields`；字段编辑：`set_field_error` /
`clear_field_error` / `clear_errors` / `set_field_label` / `set_field_required` / `set_field_help` /
`set_field_visible`；值链路：`value_of` / `field_values` / `set_value_of` / `capture_baseline` /
`dirty`；校验与动作：`validate` / `is_valid` / `error_count` / `submit` / `reset` / `refresh`；
布局：`content_rect` / `field_layouts` / `control_rect_of` / `submit_rect` / `reset_rect`；
接线：`set_registry` / `registry`。

值不存第二份：`value_of` / `set_value_of` 读写子控件自己的 `text` / `value` / `current_text`
属性；`baseline` 只在 `add_field` 与 `capture_baseline` 时捕获，供 `reset` 还原。

### 3.3 事件（8，全部有 payload 声明与 `event_signal_dyn` 臂）

`submitted`(unit) / `reset`(unit) / `submit_failed`(UInt) / `validity_changed`(Bool) /
`dirty_changed`(Bool) / `field_added`(String) / `field_removed`(String) / `field_changed`(String)。

### 3.4 接线

- 每个发布名 → 真实信号（`EventSignalRef`），测试逐个断言 `event_signal_dyn(name).is_some()`；
- 命令通道：`submit` / `reset` / `validate` / `clear_errors`，`set_*` 走属性并返回
  `OutOfRange`；
- 可选 `SimpleRegistry` 转发：坐标事件按 `field_layouts().control` 命中转发，无坐标事件广播给
  所有绑定字段（与 GroupBox 同族约定）。

### 3.5 能力

`WidgetCapability { kind: WidgetKind::Form, canonical_name: "form", aliases: ["form_panel",
"form_layout"], properties, events, commands }`，由 `install` 调 `try_register` 注册；重名返回
`RegistrationError::NameTaken` 而非覆盖。

## 5. 布局细节（完整）

`Form`：

- 内容区 = 控件矩形 − `content_padding` − 标题带（有标题且 `show_title` 时 24 px）− 按钮带
  （`show_buttons` 时 28 + `row_spacing`）；
- 字段 row-major 装入 `columns` 个等宽列（`column_spacing` 分隔），行高 = 该行字段高度最大值，
  行间 `row_spacing`；
- 单字段高度 = 标签行（left 模式与控件并排；top 模式 18 px 在控件上方）+ 控件最小
  `row_height` + 错误/帮助行（有错误且 `show_errors`，或有 help 时 16 px）；
- left 模式标签宽 = `min(label_width, 列宽 − LABEL_GAP − 16)`，控件占剩余宽度；
- `field_layouts()` 返回 `FormFieldLayout { key, label, control, error }`；控件矩形通过
  `set_widget_geometry` 写入子控件，树绘制器按该矩形绘制；
- 按钮行右对齐：`[ Reset ] [ Submit ]`，`submit_rect` / `reset_rect` 公开且参与命中测试。

`FormSet`：

- 头部带 = 顶部 inset 内、高 `header_height`；按页数等分，`header_item_rect(i)` 返回每格；
  `tabs` 填充当前页，`steps` 画编号/对勾 + 连接线；
- 内容区 = 头部之下 + `content_padding`，导航带之上；当前页的 Form 写入该区，其余 Form 隐藏；
- 导航带右对齐 `[ Back ] [ Next ] [ Submit ]`；`previous_rect` / `next_rect` / `submit_rect`
  公开；
- 页面导航跳过 disabled 页并环绕；越界索引**拒绝**而非钳制（不静默切到别的页）。

## 7. 后续扩展

新增分组只需：`src/<group>/mod.rs`（声明 + 再导出）、`capability.rs`（schema/构造器/install）、
每个控件一个文件；在 `src/lib.rs` 的 `install` 中加一行调用组安装器。分组自有其名称、schema 与
构造器，互不修改。

> 未覆盖：android/ios/wasm/harmony 主机运行（本机不具备）；suite 与其父 crate 一样以设备
> profile 为目标，`mini`/`embedded` 无 widget registry，不在此包范围内。
