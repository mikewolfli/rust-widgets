### 自动安装机制

**build.rs** 自动检测缺失的系统库, 编译时打印彩色安装指引:
```
cargo:warning=  ✓ alsa found (1.2.11)
cargo:warning=  ✓ webkit2gtk-4.1 found (2.52.3)
cargo:warning=  ❌ Missing: libavfilter
cargo:warning=  Missing FFmpeg development libraries. Install all:
cargo:warning=    sudo apt-get install -y libavcodec-dev libavformat-dev ...
```

**一键安装脚本** (位于 `scripts/`):
| 平台 | 脚本 | 命令 |
|------|------|------|
| Linux | `scripts/install-deps-linux.sh` | `bash scripts/install-deps-linux.sh` |
| macOS | `scripts/install-deps-macos.sh` | `bash scripts/install-deps-macos.sh` |
| Windows | 手动安装 | `vcpkg install ffmpeg` |

**Cargo 别名**:
```toml
# .cargo/config.toml
install-deps = "..."
```
运行 `cargo install-deps` 获取指引。
