## 4. 未做/边界（原则 #105）

- **没有加 criterion 计时基准**：仓库的 9 个 `[[bench]]` 受 T3-02 的 `Cargo.toml`/磁盘/runner 三方一致约束，
  新增一个 bench 要同步三处；而时间收益预计低于噪声，分配次数是确定性的且已能门禁化。若后续需要时间证据，
  再按三方同步流程补 `chart_bench.rs`。
- **池容量上限是有意行为**：超过 `1 << 16` 元素的缓冲不归还，下一次大图重分配一次；避免单次大图永久占用内存。
- **内存上界**：每 UI 线程最多保留约 `8N + 8(2N+2)` 字节（N 为最大点数），且受上限保护。
- 未测量真实帧时间；本轮收益口径是“稳态零分配 + 可回归门禁”，不声称 FPS 提升。
