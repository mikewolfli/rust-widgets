## 修正清单

### Round 1 (并行任务)

#### 1.1 🔴 Image Decoder - JPEG 占位修复 `src/image/decoder.rs`

**问题**: `decode_jpeg()` 返回灰度占位像素 (`vec![128u8; ...]`)，非真正的 JPEG 解码
**修复**: 替换为返回明确的错误信息
```rust
// Before: return grayscale placeholder
let pixels = vec![128u8; ...];
// After: return clear error
Err("JPEG decoder not implemented — use PNG or BMP format instead".into())
```
**证据**: `decode_jpeg_detects_dimensions` 测试从 `is_ok()` 改为 `is_err()`

#### 1.2 🔴 Image Decoder - SVG 占位修复 `src/image/decoder.rs`

**问题**: `decode_svg()` 返回浅灰占位像素 (`vec![240u8; ...]`)，产生误导性数据
**修复**: 替换为完全透明像素，移除误导性注释
```rust
// Before: Light gray placeholder
let pixels = vec![240u8; fw as usize * fh as usize * 4];
// After: Fully transparent placeholder
let pixels = vec![0u8; fw as usize * fh as usize * 4];
```

**问题**: 所有测试依赖 SVG 加载，但 SVG 现返回透明图像而非有效数据

- 新增 `make_red_bmp()` 辅助函数构建有效 24-bit BMP
- 更新 7 个测试使用 BMP 数据：

  - `image_rotate` → 10x10 BMP
- 图片测试: 87 passed, 0 failed
