## 3. 本轮新发现与修复（N3-*）

> 编号 `N3` = 2026-10-23。每条给出“缺陷 → 修复 → 证据”。全部先读源码取证，再改。

### 3.1 渲染正确性（影响全部 188 个控件）

**N3-01 半透明填充把背景“挖洞”而不是合成（P1）**
- 位置：`src/render/pipeline/pixel_ops.rs` `write_pixel_with_mode`。
- 缺陷：`coverage >= 1.0` 时走 `set_pixel` 原样写入 RGBA，丢掉目标像素。帧是 straight-alpha、在 macOS blit 时才预乘，所以 elevation 阴影（alpha 40–70）、scrim（alpha≈80）、`Material::Translucent` 面（alpha 230）都把下层 RGB 抹掉，留下半透明孔洞；同一形状的抗锯齿边缘却走合成，形成硬接缝。
- 修复：仅当 `coverage >= 1.0 && color.a == 255` 才走 `set_pixel`；其余走 source-over。
- 证据：新增 `translucent_fill_composites_over_the_backdrop`、`a_low_alpha_shadow_darkens_instead_of_cutting_a_hole`；`cargo test --lib` 7621 通过；`check_visual_regression` 通过。

**N3-02 非 ASCII 十六进制颜色会让进程 panic（P2）**
- 位置：`src/style/css.rs` `parse_hex_color`。
- 缺陷：`hex.len()` 是字节数，`&hex[0..2]` 假设 ASCII；`#日本` 是 6 字节，切片落在字符中间直接 panic。调用方包括 stylesheet、JSON 属性、C ABI。
- 修复：切片前 `bytes().all(is_ascii_hexdigit)`，非法值走正常 `Err`。
- 证据：新增 `a_non_ascii_hex_colour_is_rejected_without_panicking`。

**N3-03 未知伪类被静默丢弃，选择器过度匹配（P2）**
- 位置：`src/style/css.rs` `parse_selector`。
- 缺陷：`Button:hoover`（拼写错误）解析成 `Kind("Button")`，于是“悬停规则”永久作用于所有按钮。与同文件对未知 kind 返回 `None` 的策略相反。
- 修复：未知 `:state` 让整个选择器返回 `None`（匹配不到）。
- 证据：新增 `an_unknown_pseudo_class_makes_the_selector_match_nothing`。

**N3-04 CSS specificity 被计算却从不使用（P2）**
- 位置：`src/style/stylesheet.rs`、`src/style/css.rs`。
- 缺陷：运行时按源码顺序应用，`.primary` 写在 `Button` 之前时会被后者覆盖——与 CSS cascade 相反。`selector.rs` 的 specificity 只服务于另一个未使用的类型。
- 修复：`CssSelector::specificity()`；注册时固化进 `ParsedRule`；`apply_to` 按 `(specificity, source_order)` 排序后应用。
- 证据：新增 `a_class_rule_overrides_a_kind_rule_written_after_it`、`specificity_ranks_a_class_above_a_kind`。

**N3-05 一个坏 stylesheet 取消整个 CSS 层（P2）**
- 位置：`src/style/stylesheet.rs` `apply_to`、`src/json/loader.rs`。
- 缺陷：遇到 `parse_error` 立刻 `return Err`，其余合法 sheet 全部不应用；JSON loader 又在 `Err` 时丢弃整个 style，于是 **一条坏应用级 sheet = 所有控件无 CSS**，与其文档“报告并跳过”不符。
- 修复：跳过坏 sheet、应用其余、循环后仍返回首个错误；loader 无论成败都安装已应用的 style。
- 证据：新增 `a_broken_sheet_does_not_discard_the_valid_sheets`；原有 `stylesheet_invalid_css_returns_error` 保持通过。

**N3-06 SVG 文本忽略 letter-spacing，与光栅后端不一致（P2）**
- 位置：`src/render/svg/backend.rs` `emit_text`。
- 缺陷：`shape_line` 把 tracking 加入总 advance，光栅在簇之间加 tracking，SVG 两者都没有：带字距的文本在 SVG 中更窄，居中标签偏左。
- 修复：SVG 循环在簇之间加 `font.letter_spacing() * dpi_scale`。
- 证据：`cargo test --lib -- render::` 417 通过；`check_svg_snapshots` 398 文件字节一致（默认字体字距为 0，快照不变）。

**N3-07 flex 可把主轴尺寸算成负数，`as u32` 后约 42 亿像素（P2）**
- 位置：`src/layout/flex.rs` G-1 重缩放。
- 缺陷：gaps 大于可用主轴时 `budget` 为负，整数乘除产生负尺寸，后在 `main_len as u32` 变成 `u32::MAX-…`。
- 修复：`budget.max(0)`；矩形构造处 `main_len.max(0)` / `cross_len.max(0)`。
- 证据：`cargo test --lib -- layout::` 361 通过。

**N3-08 移除栈中较早页面会切换当前页（P2）**
- 位置：`src/layout/stack.rs` `remove_widget`。
- 缺陷：`retain` 后只钳尾部索引；`[A,B,C]` 当前 B，删 A 后显示 C。
- 修复：先定位索引，套用 `remove_at` 的同一条规则。
- 证据：新增 `remove_widget_keeps_the_same_widget_selected`。

**N3-09 零尺寸项让换行失效（P3）**
- 位置：`src/layout/flex.rs`、`src/layout/wrap.rs`。
- 缺陷：`used > 0` 使“只含零尺寸项的当前行”永不换行，后续超宽项被塞进同一行、落到不同 `y`。
- 修复：依赖 `count > 0` / `line` 非空，删除 `used > 0`。

**N3-10 网格余数分给错误的列（P3）**
- 位置：`src/layout/grid.rs`。
- 缺陷：除数用列索引 `cols - idx` 而不是剩余桶数；四等分、余 3px 时第一列（最大 stretch）拿 0，最后一列拿 1。
- 修复：按 `indices.len() - slot` 分配。

**N3-11 阿拉伯语 harakat / 韩文 jamo 未被当作组合标记（P2）**
- 位置：`src/render/grapheme.rs`。
- 缺陷：库自带阿拉伯字形，但 `U+0610..061A`、`U+064B..065F`、`U+0670`、`U+06D6..06ED` 不在组合范围内，每个音符成为独立簇，画出 1px 碎片并破坏间距。
- 修复：补齐阿拉伯标记与 `U+1160..11FF`。证据：扩展 `the_predicates_cover_their_documented_ranges`。

**N3-12 大半径实心圆 `i32` 溢出（P3）**
- 位置：`src/render/pipeline/primitives.rs` `fill_circle`。
- 缺陷：半径 > ~46k 时 `r*r` 溢出（debug panic / release 变形），与 `fill_circle_aa` 的浮点实现不一致。
- 修复：平方改用 `i64`。

**N3-13 `with_padding/margin/shadow/touch_target/gradient/opacity` 不清 `theme_derived`（P3）**
- 位置：`src/style/primitives.rs`。
- 缺陷：`merge_theme` 会在下一次状态/主题变化时把这些“调用方显式值”整体覆盖；`with_background` 等已正确清除，六个兄弟漏了。
- 修复：六个 builder 置 `theme_derived = false`。

**N3-14 `property_animations` 只增不删（P3）**
- 位置：`src/style/animation.rs`。
- 缺陷：完成、`remove`、`clear` 只清 `animations`，每次 `animate()` 遗留一个含 `String` 的元数据；`get_property_animation` 永远返回过期项。
- 修复：三条移除路径同步清理。证据：新增 `property_metadata_is_dropped_with_the_animation`。

**N3-15 `Transition::tick` 每次调用构造并丢弃一个 `AnimationDriver`（P3）**
- 位置：`src/style/animation.rs`。
- 缺陷：每帧每动画分配 `HashMap` + `Rc<Cell>` + boxed 回调，结果从未读取；实际值由手写公式得到。
- 修复：删除死构造，保留实际插值；同步更新过时注释。

### 3.7 明确未实施（具名，不计入闭合，原则 #105）

| 项 | 为什么不做 |
|---|---|
| 语义数据源的 `revision() == 0` 时启用窗口缓存 | 默认 0 表示“数据源不支持版本号”。在无失效契约时缓存会返回陈旧数据——这是正确性风险，不是性能优化。 |
| `SurfaceShadow::blur` 未参与绘制（阴影仍是实心矩形） | 模糊由 `PaintBackend` 的 `BoxShadow` 实现，而控件走 `RenderContext` 像素管线；需要先在管线层增加模糊原语，属结构性改动。本轮记录，不冒险改共享绘制栈。 |
| `BoxLayout::update_with_context` 忽略 `item.align` | 该入口不接收 `ChildInfo`，无法取得子控件首选交叉尺寸；要修必须先给 `BoxItem` 增加显式交叉尺寸（公开 API 扩面）。 |
| `combo_box.items` / `roller.options` / `breadcrumb.segments` / `image_gallery.images` / `sparkline.data` | `CapabilityValue` 没有“字符串列表”种类；`Records` 要求唯一 id，重复 label 的组合框/滚轮条目会被误拒。正确解法是新增列表型 `PropertyValueKind`（跨 types/records/JSON/designer 的公共契约），本轮不凭空发明。**推荐后续按此方案实施。** |
| CodeEditor 每行 `line_text()` 克隆、ShortcutEditor 分组缓存、`draw_text_fitted` 返回 `String` | 与上一轮同一具名 API/结构边界（`docs/log/log-20261022-2.md` §5），维持原判断。 |
| `HX-03` 巨文件拆分 / `PLAT-12` 首次粘贴 E2E | 用户已裁定取消 / 环境受限，维持原状。 |
