## 5. API 变更与迁移说明（原则 #21）

`Profiler` / `PerformanceMonitor` 的 `begin`、`measure`、`begin_section` 现在要求 `&'static str`：

```rust
// before
profiler.begin(name);              // name: &str
// after
profiler.begin("layout");          // 必须是编译期字面量或 &'static str
```

理由：旧实现每次 `begin` 都 `name.to_string()`，测量设施本身在帧路径上分配（G-30）。仓库内调用点已逐处核对：生产代码仅 `PerformanceMonitor::begin_section` 转发，其余为测试中的字面量，无下游动态字符串调用。`Profiler::get_all_stats` 的返回类型随之变为 `&HashMap<&'static str, ProfileEntry>`；`get_hotspots` 的 `&str` 返回值不变。
