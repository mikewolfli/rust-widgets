### 4.3 性能优化 — widget_trait.rs 消除 `style().clone()`（8 处）

**问题**: `set_background_color`, `set_foreground_color`, `set_font`, `set_border_color`, `set_border_width`, `set_border_radius`, `set_padding`, `set_margin` 都先克隆整个 Style 再修改一个字段再 set 回去。

**修复**: 利用 `BaseWidget::style_mut()` 原地修改，完全消除克隆。

```diff
- let mut style = self.style().clone();
- style.background_color = color;
- self.set_style(style);
+ self.base_mut().style_mut().background_color = color;
```
