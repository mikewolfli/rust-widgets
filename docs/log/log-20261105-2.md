## 3. ⚠️ Plan 信息不足 / 计划与代码不符（需人工确认）

1. **API2-01**（issue §1.3）：要求“把 ConstraintLayout/AbsoluteLayout 接入 `SUPPORTED_TYPES` 使 JSON 可达”。`SUPPORTED_TYPES` 只含布局类型 token，而这两个求解器的数据是**每个子控件**一份（`ConstraintRef`/`AbsolutePosition`），计划未定义该 JSON schema。未臆造。
2. **ADV2-02 像素差异**（见 §1.1）：统一到 `KeyTipBadge::paint` 后 tip 字体由 Arial 14 regular 变为 bold 11.2。要逐像素一致需给 badge 增加字体槽。
3. **WV-03 schema 位**：计划说“补 get 臂”，但原 schema 是 `(false,false)`，工厂在控件之前就拒绝读；已改为 `(true,false)`。
4. **FIN-8 守卫位置**：计划写“在 `base.handle_event(event)` 之后补守卫”，但四处 `base.handle_event` 都是函数最后一句，按字面加会是死代码；已按 candlestick/volume 的实际写法放在 poll 之后、路由 match 之前。
5. **MW2-01 路径**：`src/widget/misc_widgets/cupertino/nav_bar.rs` 不存在，实际在 `src/widget/cupertino/nav_bar.rs`。
6. **CH2-04 缓存键**：`set_series_visible` 只 bump `visibility_generation`、`set_series_names` 只 bump `names_generation`，故键必须是四项；pie 侧不能用 `angles_dirty`（它被 `ensure_angle_cache` 清空，且会被无关 scrub 触发），改用 `values_revision`。
7. **CP2-5 `note_entry_hover`**：唯一正确调用点在 `runtime/pointer.rs` 的 hover 转发；本轮无代理拥有该文件，故收窄为 `pub(crate)` 并写明接线点，**未接线**。
