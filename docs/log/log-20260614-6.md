## Round 2: Ultra-Deep Scan — 8 More Critical Issues Found & Fixed

After the initial scan claimed 98%, a second ultra-deep scan revealed **8 more real bugs** that needed fixing:

### 🔴 Bug 1: MKV vs WebM Detection Broken
**File:** `src/video/format.rs` (lines 92-99)
**Root Cause:** Two identical `if` blocks checked the same EBML header. First returned `Mkv`, making the second (WebM) dead code. **WebM was always undetectable.**
**Fix:** Merged into single block. Scans for `"webm"` DocType string at offset ~44. If found → `WebM`, else → `Mkv`.

### 🔴 Bug 2: AAC Falsely Detected as MP3
**File:** `src/audio/decoder.rs` (lines 15-33)
**Root Cause:** Raw MP3 sync check (`0xFF & (byte1 & 0xE0) == 0xE0`) ran **before** AAC ADTS check (`0xFF & (byte1 & 0xF0) == 0xF0`). Since AAC frames (`0xFFFx`) are a subset of MP3 sync range (`0xFFEx–0xFFFF`), every AAC frame was classified as MP3.
**Fix:** Moved AAC check before MP3 sync. Added `(data[1] & 0x08) == 0x08` for AAC; MP3 now excludes AAC range with `(data[1] & 0xF0) != 0xF0`.

### 🔴 Bug 3: Platform Runtime String Mismatch
**File:** `src/platform/runtime.rs` (line 201)
**Root Cause:** Match arm had `"android-mobile"` but `AndroidPlatform::backend_name()` returns `"android-state-backend"`. Missing entries for macOS fallback, iOS stub, Harmony stub.
**Fix:** Added all actual backend names:
```rust
"harmony-desktop" | "harmony-state-backend" | "macos-objc2-preview"
| "macos-fallback-stub" | "android-state-backend" | "ios-mobile-stub"
=> RuntimeGuiMode::PreviewOrStub,
```

### 🔴 Bug 4: PDF Export Embeds SVG as Invisible Comments
**File:** `src/pdf/export.rs`
**Root Cause:** `build_content_stream()` wrapped SVG content in `% BEGIN SVG CONTENT` / `% END SVG CONTENT` PDF comments. Standard PDF viewers rendered **nothing** — the file was structurally valid but visually blank.
**Fix:** Replaced comment-based approach with real PDF content operators:
- `svg_to_pdf_operators()` — converts `<rect>`, `<circle>`, `<path>` SVG elements to PDF operators (`re`, `m`, `c`, `l`, `f`, `B`, `S`, `rg`, `RG`)
- `extract_attr()` — XML attribute extraction via string search
- `parse_svg_color()` — `#RRGGBB` → normalized RGB floats
- `svg_path_to_pdf()` — SVG path `d` strings → PDF path operators

### 🟡 Bug 5-8: Missing i18n Keys (7 keys across 3 languages)
**Files:** `language/en.json`, `language/zh-cn.json`, `language/zh-tw.json`
**Missing keys:** `widget.color_dialog.label`, `widget.file_dialog.label`, `widget.font_dialog.label`, `widget.input_dialog.label`, `widget.message_box.label`, `widget.progress_dialog.label`, `widget.radio_button.label`
**Fix:** Added all 7 keys in alphabetical order to all 3 language files with proper translations.
