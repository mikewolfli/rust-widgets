## 3. 关键修复说明

### 3.1 T3-01：声明式引擎移除路径不再泄漏

`src/view/engine.rs` 新增：

- `release_removed_controls(ids)`：逐 id `runtime::unregister`，`#[cfg(full_widgets)]` 下再 `app::remove_callbacks`；
- `mount_built` 在 `clear_structure` 返回后调用；`commit_update` 在 `report.removed = applied.removed_ids` 后调用。

回归测试 `a_removal_unregisters_the_control_from_the_runtime` 覆盖 mount → update 移除 → 运行时注册表回落。

### 3.2 T3-04/05/16/17：RTL 拖拽同根四件

- DataGrid：`resize_handle_at` 命中镜像列的**尾边**（RTL 下左缘）；`events.rs` 的 `delta` 在 RTL 下取反。
- GridTable：命中已是尾边，补 `start_width - delta` 的方向。
- VirtualTable：RTL 下把 2px 内缩一并镜像（先缩减后镜像），绘制与命中同一推导。
- GridViewHeader：`section_rect`/`filter_rect`/`resize_handle`/拖拽/绘制全部接 `rtl_columns`。
- 回归钉：`an_rtl_resize_drag_grabs_the_trailing_edge_and_narrows_when_dragged_right`（DataGrid / GridTable 两份）、`the_rtl_gap_and_the_painted_cell_share_one_edge`（VirtualTable）、`an_rtl_header_mirrors_its_sections_and_resize_edges`（GridViewHeader）。
- 未回退 U2-06 既有列序镜像。

### 3.3 T3-06/07：两条可致进程 abort 的路径

- `js_engine.rs`：`MAX_CALL_DEPTH = 32`（该值经实测：128 会让测试线程 8 MB 栈在多层 eval 帧下溢出；32 足够覆盖正常调用且可回归）。
- `wgpu_backend`：设备创建即安装 `on_uncaptured_error` 与 `set_device_lost_callback`，`device_lost: Arc<AtomicBool>`；`wait_idle`/`render_clear_gpu`/两个 `render_draw_commands` 入口统一走 `ensure_device_available()` 返回 `Err`。

### 3.4 T3-08/09/10：三条死通道/泄漏

- DPI：注释改为如实声明“无 per-monitor DPI 传播”，`publish_dpi_change_if_needed` 标注为 host-facing helper。
- RowSignal：`pump_idle` 同时排空 rows 队列，`has_pending()` 决定 idle 标志，纯 RowSignal 应用不再断链。
- `float_to_window`：采纳失败分支执行 `destroy_widget(window_id)`，OS 窗口与 `WINDOW_STATES` 条目一并释放。

### 3.5 T3-11：suites disabled 绘制承诺

`veil_if_disabled()` 作为 suite 侧共享助手（cfg：finance/maps/devtools），11 个绘制点接线：finance 6、maps compass/zoom_control/map_attribution/map_marker_detail、devtools terminal。lottie/rive 原本已用 `disabled_surface_near`，未改动。

### 3.6 T3-18/19/20/29/30/31：缓存六件

`bar_chart` 的 `value_extent_cache`（data revision 键）、`chart` 的 `readout_cache` 加 `Font`、`tool_bar` 的 `OverflowPopup` 存 rows/icons、`tree_table` 的 `column_prefix_cache`、`tooltip` 两处 spacing bits、`code_editor` 三个 label Key 的 `font_family_hash`。

### 3.7 T3-12/13/14/21/22/23/24：子系统加固

`next_frame` 结束态与重播、SOF 尺寸轻解析与分配守卫顺序、`MAX_COPIES`、零质量弹簧、帧 delta 上限、监听器 Drop guard、SurfaceHandle 回调清理。

### 3.8 T3-25/26/27/28/32：文档与生成器口径

四套 webview 历史模型分工、`control.md` 生成器算术与重生成、CHANGELOG 同步、C++ 绑定子集边界、MIGRATION_GUIDE 计数。

### 3.9 T3-33…T3-56：卫生批量
