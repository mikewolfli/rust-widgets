| # | 文件 | 改动 |
|---|---|---|
| 1 | `carousel.rs` | `CarouselIndicatorStyle` 增 `Numeric` 变体 |

## 4. 🔴 缺口二（本轮修复）：滑动翻页缺「速度」判据

### 4.1 缺口取证

`blue17.md` §四 B1-2 的原文要求（`blue17.md:263`）：

> **滑动翻页**：接 `MousePress` → `MouseMove` → `MouseRelease`，松手按**位移阈值 + 速度**决定前进/回退/吸附

而实现只有位移：

```bash
$ grep -n "velocity\|speed\|Instant" src/widget/container_widgets/carousel.rs
（0 命中 —— 修复前实跑）
```

第 28 轮日志（§5.3）把 B1-2 记为完成，但**没有一个测试或代码提到速度**。
同样是「计划要求两项判据、实现只做一项」（原则 #13）。

### 4.2 修复设计（含本次的判断选择，用户要求 5）

| 判断项 | 选择 | 理由 / 反例 |
|---|---|---|
| 时间源 | `std::time::Instant`（单调钟） | `SystemTime` 会被 NTP 回调而出现负速度；`instant` crate 会新增依赖（原则：优先既有依赖） |
| 采样点 | 每次 `MouseMove` 记录 `last_x` + `last_moved_at`；释放时用 `pos.x` 作第二个样本 | 用整段手势的总时长会把「快─停」误判为慢；末段速度才是用户表达 |
| 速度函数签名 | `swipe_velocity_px_per_sec(last_x, release_x, last_moved_at, now, width)` | **`now` 由调用方传入**（而非内部 `last_moved_at.elapsed()`）：这样它是**纯函数**，测试能用构造的 `Instant` 断言精确算术，不必 `sleep` |
| 击发阈值 | `FLICK_VELOCITY_PX_PER_SEC = 400.0` | 约等于手机上「每秒 1/4 屏宽」。低于此会与「点击时手抖」重叠；高于此则正常甩动会被忽略 |
| 反抖动下限 | `MIN_FLICK_FRACTION = 0.02`（300px 控件 = 6px） | 一帧内几像素的抖动可算出极大瞬时速度。下限低于任何有意的滑动，因此只排除噪声 |
| 上限 | 速度钳到 **10 × 宽度 / 秒** | 见下 §4.3 —— 这是本轮**唯一被我自己的测试推翻又修正**的取值 |
| 判定顺序 | **先距离，后速度** | 距离达标者永远翻页，与释放快慢无关。速度规则只**增加**可识别的甩动，绝不取消已成立的滑动 |

### 4.3 🔍 一次被自己的测试推翻的取值（取证过程保留）

初版把速度上限写成「**1 × 宽度/秒**」，理由是「上限只要够小就能防炸」。测试立刻失败：

```bash
100px in 250ms must read as 400px/s, got 300
```

**根因**：300px 宽的控件上，上限 300px/s **低于** 400px/s 的击发阈值——
即**上限把真实甩动钳到了阈值之下，速度规则永远不可能触发**。
这不只是测试写错，而是设计错误：上限必须显著**高于**阈值才有意义。

修正为 **10 × 宽度/秒**，并补一条回归测试锁死这个关系：

```rust
// carousel_velocity_is_capped_well_above_the_flick_threshold
assert!(real_flick >= FLICK_VELOCITY_PX_PER_SEC,
    "…must not be capped below it");
```

**教训（并入本轮经验）**：钳位上限是「常量之间的序关系」约束，不是单点取值；
凡引入两个相互比较的常量，必须有一条测试**直接断言这个序关系**，否则改任一个都会静默失效。

### 4.4 接线完整性（用户要求 7）

速度判据接在**真实事件路径**上，不是只在测试里可调：

```rust
// carousel.rs — Event::MouseRelease 的 Swiping 分支
let velocity = swipe_velocity_px_per_sec(
    last_x, pos.x, last_moved_at, Instant::now(),
    self.geometry().width as f32,
);
match self.swipe_direction_at(offset_x, velocity) {
    Some(step) => { if let Some(target) = self.wrapped_step(step) { self.set_current(target); } }
    None => self.page_for_click(pos.x),   // 两条判据都不成立 → 仍按点击处理
}
```

`swipe_direction(offset)` 保留为「只有位移」的形式，给**没有时钟的调用方**使用
（一次性交付整段手势的触摸后端、无时钟的测试），并在文档写明二者关系。
