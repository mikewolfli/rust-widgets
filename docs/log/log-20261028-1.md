**转换形态**（三种，均为纯机械等价改写）：

1. 链式：`theme_manager().current_theme().map(|a| a.colors.F).unwrap_or(D)` → `palette_shared().map(|c| c.F).unwrap_or(D)`。
2. 块式：`let manager = …; match manager.current_theme() { Some(active) => (active.colors.A, …), None => … }` → `match palette_shared() { Some(colors) => (colors.A, …), None => … }`，`None` 分支字面量逐字保留。
3. 同帧多字段：提升一次 `let palette = palette_shared();`，后续经 `palette.as_ref()` 读取（`Option<Rc<Colors>>` 非 `Copy`），避免一帧多次缓存查找。
