## 9. 持续改进 Round 5 — 坐标与核心几何溢出安全

### 新发现与修复

本轮从控件边界继续下钻到核心 API，发现两类基础算术风险：

1. `clamp_point_to_rect_f32` 在零宽/零高矩形上会生成反向 clamp 范围，边界值可能 panic 或得到错误坐标。
2. `pixels_to_dpi` 与 `pixels_to_dpi_i32` 对零或负 DPI scale 直接除法，可能产生无穷大或无效整数转换。
3. `Size + (u32, u32)` 直接加法可能溢出回绕。
4. `Rect::expand_to_touch_target` 将极大 `u32` 差值转换为 `i32`，可能破坏位置和尺寸。

修复：

- 零尺寸 f32 矩形按单点矩形收敛到原点
- 非正 DPI scale 返回 0
- Size 加法改为 saturating addition
- Touch target 扩展改为 u32 安全差值与饱和位置/尺寸计算
- 新增核心边界回归测试

涉及文件：

- [src/core/coords.rs](src/core/coords.rs)

## 17. 持续改进 Round 13 — Rect 变换全范围安全

### 新发现与修复

继续检查核心几何后，发现 Rect 的组合/变换 API 仍使用 i32 直接差值或把 u32 尺寸先截断为 i32：

- `union()` / `intersection()` 在跨越完整 i32 坐标范围时可能溢出
- `shrink()` / `grow()` 在极端负 padding 或大幅扩展时可能溢出
