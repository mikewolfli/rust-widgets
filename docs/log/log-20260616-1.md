## 第1轮：结构扫描 + 基础修复

### 🔧 Fix 1-1: 删除重复的 MacOsImeBridge (ime_stubs.rs → ime_macos.rs)

**问题**: `ime_stubs.rs` 含有 `pub mod macos { MacOsImeBridge }`，与 `ime_macos.rs` 的 `MacOsImeBridge` 完全重复。`ime_macos.rs` 版本更完整（含 UTF-16 range tracking），但 `macos/types.rs` 引用的是 stubs 版本。

**根因**: 模块设计历史遗留 — `ime_stubs.rs` 是早期 macOS IME 桥接的 stub 实现，后来 `ime_macos.rs` 实现了完整版本但未替换引用。

**修复**:
1. `src/platform/ime_stubs.rs` — 删除整个 `pub mod macos { ... }` 块（9–208行）
2. `src/platform/macos/types.rs` — 将字段类型从 `ime_stubs::macos::MacOsImeBridge` 改为 `ime_macos::MacOsImeBridge`

**验证**: `cargo check` ✅

### 🔧 Fix 1-2: 实现 Windows IME TSF 线程管理器

**问题**: `ime_windows.rs` 中 `TsfThreadMgr` 的 `try_create()` 仅返回 `None` 并记录 warn 日志，未执行任何实际的 TSF COM 操作。

**根因**: Win32 TSF API (ctfutb.h) 的 GUID/IID 在 winapi crate 中不完整。

**修复**:
1. `Cargo.toml` — 为 winapi 添加 `libloaderapi` feature
2. `src/platform/ime_windows.rs` — 实现真正的 `msctf.dll` 动态加载：
   - 使用 `LoadLibraryA("msctf.dll")` 加载 TSF DLL
   - 使用 `GetProcAddress` 解析 `TF_GetThreadMgr` 入口点
   - 成功时返回 `Some(TsfThreadMgr)`，失败时优雅 fallback 到 state-machine 模式

**验证**: `cargo check` ✅

### 🔧 Fix 1-3: 实现 Linux IBus DBus 连接

**问题**: `ime_linux.rs` 中 `IbusConnection::try_connect()` 仅返回 `None` 并记录 warn 日志，未执行实际的 DBus 连接。

**根因**: 在 zbus feature gate 下未实现真正的 DBus 会话连接。

**修复**:
1. `src/platform/ime_linux.rs` — 实现真正的 zbus 会话连接：
   - `pollster::block_on(zbus::Connection::session())` 连接到 session bus
   - 通过 `zbus::Proxy` 调用 `org.freedesktop.DBus.GetNameOwner` 验证 IBus 守护进程是否运行
   - 成功时返回 `Some(IbusConnection { connection })`，失败时 fallback 到 state-machine

**验证**: `cargo check --features "linux-a11y"` ✅

| 文件 | 行数 | 修复 |
|------|------|------|
| `widget/input_widgets/textarea.rs` | 88 | 添加手动 `floor_char_boundary` 函数 |
| `widget/input_widgets/textedit.rs` | 63 | 同上 |
| `widget/input_widgets/lineedit.rs` | 151 | 同上 |
| `widget/input_widgets/rich_edit.rs` | 253, 261 | 同上 |
| `widget/input_widgets/shortcut_editor.rs` | 253 | 同上 |

所有文件中添加的辅助函数：
```rust
fn floor_char_boundary(s: &str, index: usize) -> usize {
    let len = s.len();
    if index >= len { return len; }
    let bytes = s.as_bytes();
    let mut i = index;
    while i > 0 && bytes[i] & 0xC0 == 0x80 { i -= 1; }
    i
}
```
