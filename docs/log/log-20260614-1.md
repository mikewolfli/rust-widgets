## 根因分析

### Warning 1: 未使用的 imports
- **根因**: `WidgetTriggerEvent` 和 `WidgetTriggerKind` 曾用于事件路由，后重构为直接方法调用
- **预防**: 在 `git commit` 钩子中运行 `cargo check`

### Warning 2: ibus_available 死代码
- **根因**: 字段仅在 `#[cfg(test)]` 中读取，product build 中 dead
- **预防**: 这种模式在 Rust 中是合法的，添加 `#[allow(dead_code)]` 标注即可

### 问题模式：doc test 被忽略
- **根因**: 15 个 doc examples 用 ````ignore```` 跳过编译，导致文档与代码脱节
- **预防**: 使用 `no_run`（需编译但不执行）或 `text`（纯文本不编译）

### 问题模式：clippy 警告堆积
- **根因**: 长期缺乏 clippy 运行，147 项警告积累
- **预防**: CI 中使用 `cargo clippy -- -D warnings` 强制零警告
