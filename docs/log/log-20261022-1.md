## 2. cookbook 与实际项目对齐（实质内容，不只是数字）

### 2.1 新增 Media 模块章节（三语）

`api-reference.md`（en / zh-CN / zh-TW）此前声称“module-by-module 覆盖整个公开 API”，但没有
`audio` / `video` / `image` 三个模块。本轮各语言新增 `Media Modules (`audio`, `video`, `image`)`
章节，内容严格取自源码签名：

- `AudioEngine`：`new`、`load`、`load_async`、`is_loading`、`poll_load`、`wait_for_load`、
  `play`/`pause`/`stop`、`set_volume`/`volume`、`tick`、`current_samples`、`duration_seconds`、
  `play_to_device`（`audio-output`）；
- `VideoEngine`：`open`、`with_decoder`、`metadata`/`duration`、`play`/`pause`/`stop`、`seek`、
  `tick_frame`、`next_frame`/`step_frame`、`take_dropped_frames`、`clock`/`clock_mut`；
- `image::decoder`：`decode`、`decode_async` → `ImageDecodeJob::wait`/`try_take`、
  `decode_to_rgba8`、`decode_animation`、`detect_format`；
- 三个模块的特性门（`audio`/`video`/`image`）与 2.8.14 起的“后台解码 + 同步回退”契约。

TOC 相应插入第 33 项，后续三项顺延（33→34、34→35、35→36）。

`pdf-encryption`、`js-engine`、`web-http`。
