## Round 2: Fixes Applied (Batch 1 - Critical)

### Fix 1: `src/core/geometry.rs` — NaN/clamp protection in Rect::from_f32/from_f64
**Issue:** `Rect::from_f32` and `Rect::from_f64` had unsafe `as i32` casts that could cause undefined behavior with NaN, +inf, or out-of-range values.
**Fix:** Added `.clamp(i32::MIN as f32, i32::MAX as f32)` for x/y and `.min(u32::MAX as f32)` for width/height.
**Files:** `src/core/geometry.rs` (lines 260-265, 307-312)

### Fix 2: `src/layout/constraint.rs` — RightToLeft/BottomToTop logic bug
**Issue:** `RightToLeft` produced same result as `RightToRight` (both aligned to target's RIGHT edge). `BottomToTop` same as `BottomToBottom`. Violates semantic meaning.
**Fix:** `RightToLeft` now aligns widget right edge to target LEFT edge: `target_rect.x - widget_rect.width + offset`. `BottomToTop` aligns to target TOP edge.
**Files:** `src/layout/constraint.rs` (lines 119-147)

### Fix 3: `src/layout/flow.rs` — add_widget/remove_widget were log::warn stubs
**Issue:** `FlowLayout::add_widget()` and `remove_widget()` emitted `log::warn!` and did nothing, breaking the `Layout` trait contract.
**Fix:** Added `widget_ids: Vec<ObjectId>` field to properly track ObjectIds. `add_widget` pushes unique IDs; `remove_widget` retains non-matching. `update()` maps positional indices to actual ObjectIds via the new field.
**Files:** `src/layout/flow.rs` (struct, impl Layout)

### Fix 4: `src/event/loop.rs` — drain_tasks() never called in EventLoop::start()
**Issue:** `schedule_task()` / `drain_tasks()` system was structurally complete but `EventLoop::start()` never called `drain_tasks()`. All scheduled tasks silently leaked.
**Fix:** Added `crate::event::types::drain_tasks()` call as Phase 0a in the event loop iteration, right after native pump.
**Files:** `src/event/loop.rs` (lines 102-103)

### Fix 5: `tests/blue9_r6_platform_capability_test.rs` — Duplicate WidgetKind::Toolbox
**Issue:** `WidgetKind::Toolbox` appeared twice in `all_widget_kinds_have_non_empty_debug_repr` list (once in native-required, once in custom-only). Toolbox has a native implementation.
**Fix:** Removed the duplicate entry from the custom-only section.
**Files:** `tests/blue9_r6_platform_capability_test.rs` (line 210)

### Fix 6: `src/control_backend/routing.rs` — 7x Duplicate WidgetKind::Toolbox
**Issue:** `WidgetKind::Toolbox` appeared 7 times across 4 test lists (2 duplicates in `custom_required_widget_kinds`, 2 duplicates in `all_widget_kinds_are_routed`, repeat in second list).
**Fix:** Removed all duplicate entries, leaving one Toolbox per list.
**Files:** `src/control_backend/routing.rs` (lines 280, 301, 435, 459)

### Fix 7: `src/core/color.rs` — Color::from_rgba_u32 duplicate implementation
**Issue:** `from_rgba_u32` (line 219) had byte-for-byte identical implementation to `from_u32_rgba` (line 57).
**Fix:** Made `from_rgba_u32` delegate to `from_u32_rgba` as a const-compatible alias.
**Files:** `src/core/color.rs` (lines 219-226)

### Fix 8: AssetWatcher consolidation (`src/asset/watcher.rs` + `src/util/asset_watcher.rs`)
**Issue:** Two almost identical `AssetWatcher` implementations: `src/asset/watcher.rs` (196 lines, simpler) and `src/util/asset_watcher.rs` (177 lines, richer events with kind/timestamp, recursive mode, drain method).
**Fix:** 
- Merged richer API into `src/asset/watcher.rs`: added `watch()` method with recursive mode, `drain()` method, richer `AssetEvent::FileChanged` with `kind` and `timestamp` fields.
- Made `src/util/asset_watcher.rs` a thin re-export layer: `pub use crate::asset::AssetEvent; pub use crate::asset::AssetWatcher;`
- 373 lines of code reduced to ~230 + 5 lines.
- All 7 tests pass (3 original + 4 consolidated).
**Files:** `src/asset/watcher.rs`, `src/util/asset_watcher.rs`

## Round 3: Fixes Applied (Batch 2 - Medium Priority)

### Fix 9: `src/embedded/input.rs` — Division by zero risk
**Issue:** `dx / duration.as_secs_f32()` could divide by zero on systems with sub-microsecond timers.
**Fix:** Protected with `.max(1e-6)` to ensure minimum non-zero divisor.
**Files:** `src/embedded/input.rs` (lines 163-164)

### Fix 10: `src/i18n/global.rs` — Silent failure on non-UTF-8 paths
**Issue:** `path.to_str().unwrap_or("")` silently swallowed non-UTF-8 paths, passing empty string to translation loader.
**Fix:** Added explicit match with `report.errors.push()` for failed paths, and `continue` to skip malformed entries.
**Files:** `src/i18n/global.rs` (lines 24-34)

### Fix 11: `src/layout/mod.rs` — Missing `pub use inspector::*`
**Issue:** `pub mod inspector;` declared but no `pub use inspector::*;`, making `LayoutInspector` and types inaccessible through `crate::layout::*`.
**Fix:** Added `pub use inspector::*;` after grid re-exports.
**Files:** `src/layout/mod.rs` (line 28)

### Fix 12: `src/render/quality/adaptive.rs` — println! instead of log::info!
**Issue:** `log_quality_change()` used `println!` with a comment "in a real implementation this would use a logging framework".
**Fix:** Replaced `println!` with `log::info!`.
**Files:** `src/render/quality/adaptive.rs` (lines 127-133)

### Fix 13: `src/layout/grid.rs` — Dead code: column_stretch/row_stretch not used in update()
**Issue:** `column_stretch` and `row_stretch` fields stored with getters/setters but never read in `update()`. All cells got equal size regardless of stretch factors.
**Fix:** Updated `update()` to use proportional distribution: `cell_width = available_width * column_stretch / (cols * column_stretch)`.
**Files:** `src/layout/grid.rs` (lines 110-132)

### Fix 14: `src/layout/box_layout.rs` — HBoxLayout/VBoxLayout missing as_any_mut()
**Issue:** Both wrappers didn't override `as_any_mut()`, causing panic when called with the default implementation.
**Fix:** Added `fn as_any_mut(&mut self) -> &mut dyn std::any::Any { self }` to both.
**Files:** `src/layout/box_layout.rs` (lines 282-285, 353-356)

### Fix 15: `src/layout/flex.rs` — update_with_context doesn't scale gap
**Issue:** Only `padding` was scaled by `layout_scale` in `update_with_context`, but gap remained unscaled. This caused inconsistent layout in HiDPI contexts.
**Fix:** 
- Added `gap: i32` parameter to `compute_main_sizes()` and `justify_positions()` instead of using `self.gap`.
- Added `scaled_gap: Option<i32>` parameter to `compute_rects()`.
- `update()` passes `None` (uses internal gap), `update_with_context()` passes `Some(scaled_gap)`.
**Files:** `src/layout/flex.rs` (compute_main_sizes, justify_positions, compute_rects, update, update_with_context)

### Fix 16: `src/image/encoder.rs` — Clippy approx_constant error
**Issue:** `const INV_SQRT2: f32 = 0.7071067811865476` triggered `#[deny(clippy::approx_constant)]`.
**Fix:** Changed to `const INV_SQRT2: f32 = std::f32::consts::FRAC_1_SQRT_2;`
**Files:** `src/image/encoder.rs` (line 175)
