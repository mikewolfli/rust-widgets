## §1 源码问题（S-01 … S-09）

### S-01 · 两种 allocator 都只对齐偏移，不对齐真实地址 → 已修复
- 位置：`src/memory/allocators.rs`（`ArenaAllocator::allocate` / `StackAllocator::allocate`）。
- 根因：只对 `offset` 做 mask，基址本身（arena 8 字节对齐、`Vec<u8>` 仅 1 字节对齐）的余数未补偿，4096 对齐请求实际地址 `% 4096 == 3584`。
- 修复：改为对齐**绝对地址**——`aligned_addr = (base + offset + align-1) & !(align-1)`，再反算 `aligned_offset`（全程 `checked_add/checked_sub`）。两种 allocator 同根因一次修好。
- 验证：新增 `high_alignment_requests_land_on_aligned_absolute_addresses`（多对齐、多次分配、含 `#[repr(align(4096))]` 超对齐类型并实际读写）与 `an_impossible_request_leaves_the_allocator_unchanged`（拒绝不改游标）。

### S-02 · AudioEngine 启动设备播放后立即丢弃流 → 已修复
- 位置：`src/audio/engine.rs`、`src/audio/output.rs`。
- 根因：`play_to_device()` 用局部 `AudioOutput` 启动 cpal 流后返回，返回即析构，播放停止且 pause/stop/volume 失联。
- 修复：`AudioEngine` 新增 `output: Option<AudioOutput>` 字段并持有整个播放期；`play/pause/stop/set_volume` 转发到持有的输出；新增 `update()` 轮询 `is_finished()` 上报耗尽。无设备时显式 `Err`。
- 验证：`play_to_device_without_loaded_buffer_fails`、`play_to_device_without_device_fails_and_holds_no_output`、`pause_forwards_to_device_output`、`stop_drops_device_output`、`set_volume_forwards_to_device_output`、`update_notifies_when_output_finished`。

### S-03 · JS 空数组/空对象 truthiness 与 ECMAScript 相反 → 已修复
- 位置：`src/web/js_engine.rs::is_truthy`。
- 根因：Array/Object 用 `!is_empty()` 判真，违反 ECMAScript（对象恒 truthy）。
- 修复：Array/Object 恒返回 `true`；所有布尔转换调用点（`if`/`||`/`&&`/`!`/`Boolean()`/`for`）经 `is_truthy` 一致。
- 验证：`empty_collections_are_truthy_like_ecmascript_objects`、`boolean_builtin_coerces_an_empty_array_to_true`、`an_empty_array_enters_the_if_branch`、`an_empty_array_drives_logical_operators_as_truthy`。

### S-04 · Boa 全局变量桥把 Null 转成 Undefined → 已修复
- 位置：`src/web/js_engine.rs::our_value_to_boa`。
- 根因：`Null | Undefined` 合并为 `undefined()`。
- 修复：`Null → JsValue::null()`，`Undefined → JsValue::undefined()`。
- 验证：`test_boa_null_round_trips_distinctly_from_undefined`（`=== null` 语义正确）。

### S-05 · Boa 写入只读全局变量无错误反馈 → 已修复
- 位置：`src/web/js_engine.rs::set_global`。
- 根因：返回 `()`，`global.set(..., throw=false)` 结果被丢弃，属性拒绝与 setter 异常都无法回传。
- 修复：新增 `SetGlobalError { PropertyRejected, SetterThrew }` 与 `try_set_global() -> Result<(), SetGlobalError>`；旧 `set_global` 委托之，保持 API 兼容。
- 验证：`test_boa_set_global_reports_read_only_rejection`（不可写属性写 2 得到 `PropertyRejected`，读回仍 1）。

### S-06 · GPU 阶梯没有按 rung 过滤 → 已修复
- 位置：`src/gpu/backend_ladder.rs`；消费者 `src/wgpu_backend/renderer.rs`。
- 根因：遍历时 `_backends` 未使用，每轮对同一 Instance `request_adapter()`；返回 rung 标签而非 adapter 真实 backend，`is_degraded()` 失真。
- 修复：每 rung 用自身 backend 集 `enumerate_adapters` + `compatible_surface` 过滤 + power preference 排序；`tier_of_adapter` 由真实 `AdapterInfo` backend 与 device type 推导（CPU→Software）；pin 路径保留（不可用显式报错，不静默替换；Instance 仍用并集保证各 rung 可达）。
- 验证：`cpu_adapter_maps_to_software_regardless_of_backend`、`adapter_ranking_honours_power_preference`、`ladder_selects_a_real_adapter_and_reports_its_true_tier`。

### S-07 · PDF margins 只有计算接口，没有导出消费者 → 已修复
- 位置：`src/pdf/export.rs`。
- 根因：`render_pages` 用整页 `pixel_size()`，`build_content_stream` 忽略 `_settings`，margins 从不生效。
- 修复：新增 `validate()` + `content_pixel_size()`；`render_pages` 按内容区渲染，内容流发出 `q … cm` 缩放+平移；超大/负/非有限边距显式拒绝。
- 验证：`validate_rejects_bad_margins`、`margins_shift_the_content_stream`、`render_pages_uses_the_content_area`。

### S-08 · RGBA 快照比较可越界，且忽略几何差异 → 已修复
- 位置：`src/test/snapshot.rs`。
- 根因：构造不校验长度；按 stride 4 读可 panic；不持久化/比较 w×h。
- 修复：新增 `Snapshot::try_new` 校验缓冲区；`save/load` 写入/读取 magic+宽高+长度头，损坏文件明确失败；`compare` 先比几何再比长度，畸形输入不 panic。

### S-09 · PerformanceSnapshot 把 NaN 指标判成通过 → 已修复
- 位置：`src/test/snapshot.rs`。
