## 3. 本轮新发现与修复（N2-*）

> 编号 `N2` 表示 2026-10-22 第二轮。每条都给出“缺陷 → 修复 → 证据”。

### 3.1 N2-01 箱线图中位线在白底上不可见（P1，外观）

- 位置：`src/widget/special_widgets/chart.rs` `draw_box_plot_chart`。
- 原代码：中位线写死 `Color::rgb(255,255,255)`；注释还写着“background colour”。默认浅色面板正是白色 → 白底白线，箱线图最关键的统计量消失。
- 修复：取 `panel_colors_with(Some(self.style()))` 的 `surface` 作为中位线颜色。
- 证据：`cargo test --lib` 全绿；`chart` 快照无变化（示例数据为柱状图），代码路径已编译覆盖。

### 3.2 N2-02 饼图标签在暗色主题不可读（P1，外观）

- 位置：`chart.rs` `draw_pie_chart`。
- 原代码：标签墨色写死 `rgb(60,60,60)`；面板在暗色下是深色 → 对比度不足。
- 修复：`let (_, ink) = Self::panel_colors_with(Some(self.style()));`，标签用 `ink`；字体提出循环（`role_font` 每帧一次）。

### 3.3 N2-03 饼图标签可绘制到控件外（P1，布局）

- 原代码：锚点 `radius + 14` 直接作为文字左上角，既没有按文本尺寸居中，也没有边界钳制；120 px 高的控件底部扇区标签会画到 y=204 → 控件外。
- 修复：测量文本 → 以锚点为中心构造文本框 → `clamp` 到控件矩形 → 在框内绘制。百分比精度保持原行为（≥1% 整数，<1% 一位小数），只把 `format!` 换成复用缓冲 + `write_fmt`。

### 3.4 N2-04 空 `PieChart` 什么都不画（P2，完整性）

- 位置：`src/widget/chart_widgets/pie_chart.rs`。
- 原代码：`slices.is_empty()` 直接 `return`，控件区域是父容器上的一个洞；同文件的其它图表和 `ChartWidget` 都会画“No data”。
- 修复：新增 `draw_empty_state`：面板 + 边框 + 居中 `No data`（主题 surface/ink，fitted）；数据全非正/非有限时也走同一分支。
- 证据：`cargo test --lib` 全绿；`pie_chart` 快照内容不变（样例有数据，空态为新增分支）。

### 3.5 N2-05 金融轴标签用 `7 px × 字符数` 估算并画到控件外（P1，布局）

- 位置：
  - `src/widget/special_widgets/finance/candlestick_chart.rs` `draw_price_labels`
  - `src/widget/special_widgets/finance/indicator_chart.rs` `draw_labels`
- 原代码：`let width = text.len() as i32 * 7; let x = area.rect.x - 6 - width;`
  - 8 字符价格 → 宽 56，`x = 48 − 6 − 56 = −14`，标签起点在控件外；
  - 宽字形被低估。
- 修复：按 `PlotArea.left_margin` / `label_x()` 定义“预留标签列”，测量文本高度，`draw_text_fitted(..., Right)` 在列内右对齐并按需截断。字体每帧一次。
- 证据：`candlestick_chart`/`indicator_chart` 明暗快照各 8 行变化，标签左移进列内（diff 已人工核对）；快照门禁 PASS。

### 3.6 N2-06 深度图买盘面积镜像错位 + 死板配色（P1，外观/布局）

- 位置：`src/widget/special_widgets/finance/depth_chart.rs` `draw_step_curve`。
- 原代码：
  - 买盘按 best-first 排列，`to_x` 随循环递减，但填充用 `Rect::new(from, ..., |x-from|, ...)`，实际画到 `[from, from+(from−x)]`，即朝价差方向偏一格，越过 spread；
  - 填充色是近黑绿/近黑红两个字面量，浅色主题下是两块黑板。
- 修复：`from.min(x)` 作为起点；填充色改为 `color.blend(&surface, 0.80)`（`color` 是该侧 bid/ask 数据色，`surface` 来自面板 chrome）。
- 证据：`depth_chart` 明暗快照各 16 行变化，矩形 x 从 `130/109/89/68` 修正为 `109/89/68/48`，颜色随主题（diff 已人工核对）；快照门禁 PASS。
