## 2. 实施

### 2.1 共享实现宏

19 个控件的存储类型不同（`usize` / `i32` 像素 / `u32`），方法名也不同
（`scroll_offset` / `set_scroll_offset` / `scroll_to_row`）。为避免 19 份近似重复代码，
在 `scroll_surface.rs` 增加 `crate::impl_scrollable_rows!`：

- 四个表达式参数：`row` / `set` / `visible` / `height`，全部在控件自己的文件里绑定；
- `ensure_row_visible` 由 trait 默认实现（nearest-window），不再逐控件重复；
- 宏展开为 `impl ScrollableRows for <类型>`，clamp 仍由控件的 `set` 表达式完成。

### 2.2 逐控件接入

| 控件 | row 单位 | 实现要点 |
|---|---|---|
| command_palette | `scroll_offset` | clamp 到 `filtered_indices.len() - visible_rows()` |
| menu / context_menu | `scroll_offset` | clamp 到 `items.len() - Menu::visible_capacity()` |
| dropdown_menu | `scroll_offset` | clamp 到 `items.len() - max_visible_items()`，`row_height = ITEM_HEIGHT` |
| font_combo_box | `scroll_offset` | 复用 `set_scroll_offset`；可见数 = `max_visible_items ∩ visible_fonts` |
| layer_panel | `scroll_offset` | clamp 到 `entries.len() - visible_rows()` |
| mac_source_list | `scroll_offset / row_height` | 像素↔行换算，复用 `set_scroll_offset` |
| mention | `scroll_offset` | clamp 到 `filtered.len() - visible_row_count()` |
| menu_button | `scroll_offset` | clamp 到 `menu_items.len() - max_visible_items()` |
| menu_panel | `scroll_offset` | clamp 到 `items.len() - visible_rows()`，`row_height = MENU_ROW_HEIGHT` |
| multi_select_combo_box | `scroll_offset` | 复用 `set_scroll_offset`；新增 `MULTI_SELECT_ROW_HEIGHT = 28` |
| notification_center | `scroll_offset` | 经 `scroll_by(delta)`；`row_height` 已公开 |
| playlist_panel | `scroll_offset` | clamp 到 `tracks.len() - visible_rows()` |
| properties_panel | `first_visible_row()` | 行↔像素换算；`row_height = ROW_HEIGHT` |
| property_grid | `scroll_offset` | clamp 到 `max_scroll()`；`visible = visible_row_count()` |
| query_builder | `scroll_offset` | 复用 `set_scroll_offset` |
| shortcut_editor | `scroll_offset` | 新增 `SHORTCUT_ROW_HEIGHT = 22`；可见行数按绘制行计 |
| timeline_widget | `scroll_offset` | 经 `scroll_by(delta)`；可见数 = `visible_count()` |
| toast_stack | `scroll_offset` | 复用 `set_scroll_offset` |
| tool_box | `scroll_offset` | 复用 `set_scroll_offset`；可见数按 `item_extent()` |
| suggestion_popup（companion） | `scroll_offset()` | 无 capability 行，只实现 trait；单测钉住 |

### 2.3 属性/命令接线

- 19 个 capability 行的属性表加入 `scroll_row`（UInt / 可读写）。
- 19 个 `property_names` 加入 `"scroll_row"`。
- 19 个 capability 的命令表加入 `"set_scroll_row"`（`menu` 与 `context_menu` 各一条）。
- `access.rs` 的 16 个 `WidgetKind` 默认值表加入 `"scroll_row" => UInt(0)`。
  `CommandPalette` / `NotificationCenter` / `MacSourceList` 共用 `ListView`，其默认值已在第八轮存在。
- 所有属性读写经 `base_property_get/set` 的单一 `scroll_row` 映射，无逐控件 match 臂。

### 2.4 门控

- 删除全部 `ROW-UNIT GAP` 排除；
- `trait_impls` 增加对 `crate::impl_scrollable_rows!(Type` 的识别（宏生成 impl 不会被
  `impl ScrollableRows for` 正则看到，否则门控会谎报未实现）。

DropDownPopupHost f32 比例、FontPreview 像素变高、内部 GridWidget 等），不是实现缺口。
