## §1 修复记录

### 1. 🔴 修复 `delegate_widget!` 缺少 `base()` / `base_mut()` 导致的运行时 panic（ISSUE-01）

- **现象**：调用 `WebViewEnhanced::draw` 时，第一行 `self.base().is_enabled()` 触发 panic：`Widget::base() not implemented — override in rust_widgets::web::web_view::WebViewEnhanced`。
- **根因**：`delegate_widget!` 宏代理了 `Widget` trait 的大部分方法，但遗漏了 `fn base(&self)` 和 `fn base_mut(&mut self)`。由于 `Widget` trait 对这两个方法提供了默认 panic 实现，导致编译期不报错，但在绘制时一旦调用即发生崩溃。
- **修复**：在 `delegate_widget!` 宏中添加：
  ```rust
  fn base(&self) -> &crate::widget::BaseWidget {
      &self.core.base
  }
  fn base_mut(&mut self) -> &mut crate::widget::BaseWidget {
      &mut self.core.base
  }
  ```
- **验证**：添加 `test_web_view_draw_multibyte_content` 绘制单测，实测通过（90 passed）。

### 2. 🔴 修复 `ImageGallery`、`BarcodeScanner`、`WebViewEnhanced` 的未对齐 UTF-8 字节切片隐患（ISSUE-02, ISSUE-03, ISSUE-04）

- **现象**：
  - `src/widget/view_widgets/image_gallery.rs` 中缩略图标签绘制使用 `&label[..8]`；
  - `src/widget/misc_widgets/barcode_scanner.rs` 中条码数据展示使用 `&result.data[..30]`；
  - `src/web/web_view.rs` 中 HTML 预览内容使用 `&self.core.content[..200]`。
  当文本包含多字节 UTF-8 字符（如变音符号、中文字符、数学符号、Emoji）且指定字节索引恰好落在字符内部时，直接切片将引发 `byte index is not a char boundary` panic。
- **修复**：
  - 引入并调用 `crate::widget::text_utils::floor_char_boundary` 对目标截断字节位置进行向下安全对齐，确保切片区间总是合法字符边界。
- **验证**：
  - 在 `image_gallery.rs`、`barcode_scanner.rs`、`web_view.rs` 中分别增加包含多字节符号边界截断的渲染单元测试，全部通过。

### 3. 🟠 补齐 `ColorPicker` 的 `set_color` 双向数据流同步（ISSUE-05）

- **现象**：`ColorPicker` 的 `set_color` 只更新了 `self.color`、`self.alpha` 并发射事件，但未反向更新 `self.hue`、`self.saturation`、`self.value`。当外部调用 `set_color` 后再由用户微调色相/明度滑块时，内部会基于旧的 HSVA 重新生成颜色，导致颜色突变跳跃。
- **修复**：
  - 增加 `color_to_hsv(color: Color) -> (u8, u8, u8)` 函数，从 RGB 反算精确的 `(h, s, v)`（有彩色时更新色相，无彩色/灰度时保留原有色相以防色轮抖动）；
  - `set_color` 同步更新 HSVA 全套内部字段，实现状态双向对称闭环。
- **验证**：
  - 增加单测 `set_color_synchronizes_hsva`，断言绿色 RGB 映射后色相落在 120° 范围附近，饱和度与明度准确对齐。

### 4. 🟠 补齐 `LCDNumber` 的数值极值边界安全防护与 `set_range`（ISSUE-06）

- **现象**：`LCDNumber::set_min_value` 与 `set_max_value` 在输入反向极值（如 min > max）或 `NaN` 时未进行主动钳位与保护；缺乏原子设置范围的接口。
- **修复**：
  - 在 `set_min_value` 中当 `min > max` 时同步提升 `max`；在 `set_max_value` 中当 `max < min` 时同步降低 `min`；
  - 增加对 `NaN` 的安全拦截过滤；
  - 增加 `pub fn set_range(&mut self, min: f64, max: f64)` 提供原子极值设定。
- **验证**：
  - 原有全套 LCD 极值测试全部保持绿色，新边界保护测试通过。

### 6. 🟠 修复 `GridWidget` 尺寸重算遗漏与安全防除零（ISSUE-08）

- **现象**：`GridWidget` 虽实现了 `draw` 中的重算，但未在 `Widget` trait 中重写 `set_geometry`，导致外部修改尺寸时 `cell_width` / `cell_height` 缓存滞后；`update_cell_dimensions` 未做 `columns.max(1)` / `rows.max(1)` 防除零保护。
- **修复**：
  - 在 `GridWidget` 中重写 `Widget::set_geometry` 自动同步重算单元格尺寸；
  - `update_cell_dimensions`、`cell_at_x`、`cell_at_y` 统一引入 `.max(1)` 安全防除零保护。
- **验证**：
  - 增加单测 `set_geometry_updates_cell_dimensions`，验证重新设置尺寸后单元格宽高立即可用，测试通过。

### 7. 🟠 修复 `PieChart` 非正数与 NaN 异常值的安全防范（ISSUE-09）

- **现象**：`PieChart` 的 `total_value` 仅求和，若传入负数、0 或 NaN，会导致 `sweep` 为负或 NaN，扇区绘制倒转或出现反向角溢出。
- **修复**：
  - `total_value` 过滤保留有限的正数（`v.is_finite() && *v > 0.0`）；
  - `draw` 检查 `total <= 0.0 || !total.is_finite()` 并在绘制每个切片时跳过非法值。
- **验证**：
  - 增加单测 `pie_chart_non_positive_and_nan_values_safe`，断言 0.0、负数和 NaN 切片不触发崩溃，渲染正常。

### 8. 🟠 重构 `AreaChart` 堆叠模式坐标极值与累加器（ISSUE-10）

- **现象**：`AreaChart` 在 `stacked=true` 时，Y 轴极值计算仍基于各单独序列的原始数据点而非堆叠后的高度，导致堆叠后面积多边形向上溢出绘图区；此外多序列点数不一致时累加器被重复初始化清空，导致堆叠失真。
- **修复**：
  - 在 `stacked=true` 时，按所有序列的最大点长度统一累加求得各点 X 坐标处的全序列堆叠高度并据此确定 Y 轴极值与刻度；
  - 修复绘制时的累加器生命周期，确保多序列连续堆叠绘制坐标精确无溢出。
- **验证**：
  - 在 `tests/chart_module_layout_test.rs` 中新增集成测试 `area_chart_engine_renders_unstacked_and_stacked`，测试通过。
