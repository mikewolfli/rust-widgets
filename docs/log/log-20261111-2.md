### 19.3 UX6-08：overscroll 共享设施

新增 `src/widget/overscroll.rs`：

- `damp(delta)` / `damp_with(delta, divisor)`：边界外拖动按 `DAMPING_DIVISOR = 3.0` 折算（非正除数回退默认值，防止把内容推得比手指还快）。

## 24. UX-04 滚动条可见性统一（产品裁定后按推荐实施）

### 24.1 已裁定的三点（用户授权「按推荐实施」）

| 问题 | 裁定 | 理由 |
|---|---|---|
| 默认可见性策略 | **有溢出才显示**（不做滚动淡入） | 淡入需要每帧时钟 + tick；容器只在数据变动时重绘，静态 thumb 更便宜且同样诚实。一个"能滚却不给任何指示"的容器，本质是 chrome 版的"静默拒绝输入" |
| `ListView` | **overlay**（占内容区尾缘，不占 lane） | 不改已有单元格矩形，快照与命中测试的改动面最小 |
| 快照批量更新 | **接受** | 指示器本身是绘制的一部分，快照变更即预期变更，逐条写进日志 |

### 24.2 共享算术（`src/widget/overscroll.rs`）

新增两个函数，把六处手算收敛成一处：

- `content_overflows(total, visible) -> bool`：`total > visible`。
- `scroll_thumb_rect(track, total, visible, offset, width, force) -> Option<Rect>`：
  - 比例长度 `height * visible / total`，下限 24 px（比光子更可读的最小目标）；
  - travel 按 `offset / (total - visible)` 比例映射；
  - `force = false` 且内容不溢出 → `None`；`force = true` 且内容恰好装下 → 满轨（"permanent rail"，不是空 thumb）。

`force` 参数是本轮修正的一个**文档/实现不一致**：早先版本把 flag 写成"force-on 覆盖"，却在溢出判定处一律返回 `None`，于是 `set_show_scrollbar(true)` 在内容装下时**什么都不画**——比旧行为（满高 thumb）是倒退。现在 flag 真正表达"常驻轨道"，且**永远不能隐藏溢出**，`the_flag_forces_a_rail_when_the_content_fits` 把这三条都钉住。

### 24.3 接线（六容器）

| 控件 | 几何 | 变化 |
|---|---|---|
| `GridTable` | track = `rect` 右缩 2，宽 4 | flag 只作 force-on；溢出即画 |
| `TreeView` | 同上 | 同上 |
| `DataGrid` | track = `cells`，宽 6 | 同上（`show_scrollbars` 为 force） |
| `ListView` | track = `layout.content`，宽 4 | **新增**：此前完全没有指示器 |
| `VirtualTable` | track = `rect` 内缩 2/2，宽 4 | 冰山发现：仍在 `if self.show_scrollbar` 手算，本轮改为派生 + 走共享助手 |
| `VirtualList` | track = `rect` 右缩 2，宽 4 | 冰山发现：同上 |

`set_show_scrollbar(s)` 的文档在六个容器上统一为"force-on 覆盖 / 常驻轨道"，不再写"enables or disables"。

### 24.4 冰山扫描（同类全部核对）

`grep 'max(24)|max(12.0)|with_alpha(120)'` + 全量 `scrollbar/thumb` 扫描，确认其余滚动指示器：

- `ScrollArea`：mounted `ScrollBar`，有自己的可见性淡入策略 → 不在本次范围（文档写明这是刻意不同）。
- `TextArea`：委托 `Scrollbar` companion（`sync_scrollbar` + `scrollbar.is_visible()`），本身已是"溢出才显示"。
- `CodeEditor`：`draw_scrollbar` 有 `total <= rows` 早退，已是溢出才画（且 `12.0` 下限是有意更小的编辑器目标）。
- `macos::SourceList`：`scrollbar_track()` 在 `max_scroll() <= 0` 返回 `None`，已是溢出才画。
- `ScrollBar` / `TabBar` / `SegmentedControl` / `DropDownPopupHost` / `FontPreview`：各自的偏移单位不是行/像素滚动，见 `check_scrollable_census.py` 的 `SCROLL_EXCLUDED` 理由。

结论：容器族 6 个已统一；其余 5 个已有等价或刻意不同的策略，无需改动。
