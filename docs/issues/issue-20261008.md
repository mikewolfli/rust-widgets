### D09-JNI-03 · P2 · Java/Python 含 NUL 字符串在 C ABI 边界被静默改写  ✅ 已修复

### D09-EVT-07 · P2 · 禁用触摸转换不会清理活动触点，重启后可产生孤立释放  ✅ 已修复

- 证据：`TouchBegin(id)` 会将触点写入 `active_touches`；`set_enabled(false)` 只更新 `enabled`，不清理活动触点；禁用期间 `translate` 在入口提前返回，不会消费 `TouchEnd` 或移除此记录。重新启用后，同 ID 的迟到/重复 `TouchEnd` 仍可命中残留状态并转换为 `MouseRelease` 与 `MouseLeave`，即使当前启用周期没有对应的合成 `MousePress`。这使输入接管、暂停/恢复或显式开关 translator 后的触摸事件序列跨越启用周期，可能向鼠标控件发送不成对的 release。

### D09-EVT-08 · P2 · 动画帧事件可能先于 pending 登记派发，造成取消状态错误及孤儿记录  ✅ 已修复
