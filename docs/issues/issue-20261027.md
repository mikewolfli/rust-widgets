## 第 1 章 全局与引擎级问题（性能 / 隐藏全局缺陷）

> 本章条目影响面为全控件或整个子系统，优先级高于分域条目。

### 1.1 引擎性能（渲染）

**G-801 帧级软件绘制 backend 不进对象池，每次内容变化帧重新分配并清零全帧缓冲**
- **1级** `render_frame_incremental_cow` / `render_frame` / `render_frame_tree` 三条帧路径各自裸调 `SoftwarePaintBackend::new(size, 1.0)`（`src/widget/runtime.rs:6007`、`:6456`、`:6607`），而 `SoftwareSurface::new` 构造 `front: vec![0; bytes], back: vec![0; bytes]` 双缓冲（`src/render/backend/surface.rs:198-199`）；生产调用链完整：`render_frame_incremental`（runtime.rs:5863）→ cow，`render_frame_at_geometry`（:6479）→ `render_frame`。对照：layer 路径已有 `LAYER_BACKEND_POOL` / `LAYER_BUFFER_POOL`（runtime.rs:5512、:5517）按尺寸 take/return。后果：1080p 每帧分配+清零 ≈ 16.6 MB（2×W×H×4），mmap/缺页 churn 主导脏帧耗时，是当前**最大的全局丝滑度瓶颈**。
- **2级** 帧级三路径复用现有 `LAYER_BACKEND_POOL` / `LAYER_BUFFER_POOL` 同款按尺寸 take/return 机制，backend 归还时保留已分配缓冲（机制已在树内，仅扩大复用面）。

**G-802 录制路径（bucket_recording）绘制命令 payload 每次调用堆分配**
- **1级** `draw_path` 无条件 `points.iter().map(offset_point).collect::<Arc<[Point]>>()`（`src/render/backend/surface.rs:1974` 函数体内）；`draw_path_dashed` 同样无条件 collect（:1998-2001）；`fill_path_non_zero` 录制分支 `offset_points` 产 Vec + `contours.to_vec()`（:2013-2026）；`draw_text` 录制分支 `Arc::from(text)` + `font.clone()`（:2033-2053）。后果：文本+路径密集界面（表格、图标、代码视图）脏区重绘期间每控件每帧数十至上百次小分配，放大 allocator 压力与脏帧尾延迟。
- **2级** 为 bucket 录制引入帧级 arena/池化缓冲承接 payload 所有权（与现有 bucket 缓冲同生命周期，帧末统一回收）。

**G-803 wgpu CPU 栅格化圆角矩形逐像素谓词**
- **1级** `fill_rounded_rect_cpu_rgba8` 对 clip∩rect 全区域每像素调 `inside_rounded_rect`（`src/wgpu_backend/raster.rs:756-784`，谓词调用在 :780）；对照软件主路径圆角矩形已有中段整行 solid span 优化（`src/render/pipeline/primitives.rs:330-425`）。后果：CPU fallback/离屏路径上大圆角矩形 O(W×H) 次谓词调用；两套实现渐变行为不一致风险并存。
- **2级** 按行解析圆角 x 边界，中段整行写 span、仅角部带宽内逐像素，对齐 `primitives.rs` 既有做法。

### 2.1 base_widgets（B-）

**B-001 Button 图标与文字的相对排布能力缺失**
- **1级** 图标槽固定为前置（leading），无图标位置属性。证据：`grep icon_position/icon_align/IconPosition/text_position/text_side` 在 `src/widget/base_widgets/button.rs` 全部 0 匹配；`icon_rect()`（button.rs:536）与 `implicit_size`（button.rs:405-475）将图标推导为固定前导槽位。后果：图标在上/文字在下的工具条式按钮无法表达，宿主只能拼装两个控件并自行对齐。
- **2级** 增加 `icon_position: IconPosition`（含 `set_icon_position`，默认 Leading），`icon_rect()` 与 `implicit_size` 按该槽位推导，默认渲染保持不变。

**B-002 ButtonGroup 缺组级 exclusive 开关**
- **1级** 互斥语义只存在于成员控件的 `auto_exclusive`（checkbox.rs:329、radiobutton.rs:309），分组句柄本身无独占属性。证据：`grep set_exclusive/is_exclusive` 在 `src/widget/base_widgets/button_group.rs` 0 匹配。后果：把非独占成员（如 CheckBox）编入同一组时，无法在组层面强制单选/互斥。
- **2级** ButtonGroup 增加 `exclusive: bool`（默认 true 对齐现状）与 `set_exclusive`，由 hub 在成员上报时决定是否清除其余成员选中。

### 2.2 display_widgets（D-）

**D-001 Slider 缺倒置外观/倒置控制**
- **1级** 仅 `set_direction`（slider.rs:1173-1181）提供水平 RTL 翻转，纵向滑杆自下而上、「值轴反向」语义均无法表达。证据：`grep inverted/flipped/reversed` 与 `set_inverted/inverted_appearance` 在 slider.rs 均 0 匹配；同族 ProgressBar 已有先例（progressbar.rs:262-266 `set_inverted_appearance`）。后果：倒序刻度场景（温度计、自上而下进度）需宿主做值变换，刻度与步进仍按正向走。
- **2级** 增加 `set_inverted_appearance(bool)`（命名与 ProgressBar 一致），仅翻转 value↔pixel 映射与刻度端点，默认 false 行为不变。

**D-002 Roller 缺循环（wrap）选项**

- **2级** 增加 `set_wrap(bool)`，`set_selected_index` 越界时按模回绕，默认 false 维持现有钳制。

**D-003 Clock 数字表盘无 12/24 小时制**
- **1级** 数字模式硬编码 24 小时制。证据：`grep meridiem/am_pm/hour12/set_format` 在 clock.rs 0 个属性级命中；digital 分支直接 `write!(text, "{:02}:{:02}", ...)`（clock.rs:760-764）。后果：12 小时制场景无法表达 AM/PM 后缀。
- **2级** 增加 `ClockHourFormat`（`H12`/`H24`，默认 `H24`）与 `set_hour_format`，digital 分支按其渲染并追加 AM/PM 后缀（命名对齐现有 `ClockDisplay`/`ClockTimeSource`）。

**D-004 Divider 缺端部缩进（inset）**
- **1级** 分隔线始终贯穿整个矩形，无首尾留空能力。证据：`grep inset/set_inset/indent` 在 divider.rs 0 匹配（现有 API 仅 vertical/thickness/line_style/color，divider.rs:48-118）。后果：「与卡片内容边缘对齐、两端留空」的分隔线需宿主额外容器裁切。
- **2级** 增加 `set_inset(u32)`，`draw`（divider.rs:272）先按 inset 收缩线段矩形再绘制，默认 0 保持现状。

**D-005 Meter 读数仅支持 u32**
- **1级** `value()/set_value()` 均为 u32（meter.rs:158-176），小数读数无法表达。证据：同族 Rating 已有整数+精确值双轨先例（`set_rating_exact(f32)`，rating.rs:123）；LCDNumber 亦为 f64（lcd_number.rs:114）。后果：12.5℃、0.5A 等小数刻度被迫整数化，刻度标签与读数同步失真。

### 3.1 base / display
