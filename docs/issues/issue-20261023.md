### Button (`src/widget/base_widgets/button.rs`) ↔ 参考工具包 `push button`/`abstract button` — ✅ 已实施
- [属性] 缺 `shortcut`、`menu`（下拉挂载）、`autoDefault`/`autoExclusive`、独立 `flat` 属性；`iconSize` 固定为 `dimensions::BUTTON_ICON_SIZE`（button.rs:214-229）不可调；文本仅单行 → 增 `set_icon_size`、`shortcut: Option<Vec<u32>>`、`menu` 属性与 hit-test 弹出。
- [方法] 缺 `set_menu/set_shortcut/set_auto_default` 等价 API。
- [操作] 缺右键菜单、DnD。
- [动画] PropertyDriver hover=0.5/press=1.0（button.rs:96, 377-388）优于 参考工具包 ≈持平偏优。
- [丝滑] 文本 fitted 绘制；缺 `参考工具包::Elide*` 等省略等级控制。
- [macOS] default 强调环（:1117）贴合 HIG；flat 形态缺失。

### Checkbox (`base_widgets/checkbox.rs`) ↔ 参考工具包 `check box` — ✅ 已实施
- [属性] 三态 CheckState（:53-60）覆盖 参考工具包 PartiallyChecked；缺 `autoExclusive`。
- [组成/操作] **draw 无焦点环分支**（:516-643 无 focus ring）→ Tab 后无可见键盘焦点即不可用键盘导航（HIG 硬伤）；参照 radiobutton.rs:617-630 已有实现补齐。
- [动画] 无按压/hover 过渡，库内 Button 有 → 库内不一致（见共性 1）。

### Frame (`base_widgets/frame.rs`) ↔ 参考工具包 `frame` — ✅ 已实施
- [属性] 6 shape+3 shadow（:31-107）≈参考工具包；Box raised/sunken 的 bevel 硬编码 1px 忽略 `line_width`（:293, 334）；Box/WinPanel 不读 `border_radius` → bevel 宽度=`line_width`，shape 绘制统一消费 border_radius。
- [方法] 缺 `contentsMargins`、独立 frameWidth 语义 → 增 margin 并在子内容布局中扣除。
- [macOS/3D] bevel 用无主题字面量色（:284-288）→ 改主题派生；Bevel 仿光影（:255-349）是库内唯一光影表达。

### Label (`base_widgets/label.rs`) ↔ 参考工具包 `label` — ✅ 已实施
- [组成] 仅单行文本；参考工具包 label 支持 pixmap/富文本 → 内容模型差距最大的控件之一。
- [属性] 仅 text+alignment（:36-74）；缺 `wordWrap`、`textFormat`、`pixmap`/`scaledContents`、`margin`/`indent`、`openExternalLinks`、`selectedText`、`buddy` → 至少先加 `word_wrap` 与 `margin`（换行原语可复用 alert_dialogs.rs:207 `wrap_words`）。
- [丝滑] `draw_text` 无省略无换行（:238-244），长文本溢出破坏布局 → 加 elide+wrap 路径。

### Radiobutton (`base_widgets/radiobutton.rs`) ↔ 参考工具包 `radio button`/`button group` — ✅ 已实施
- [属性] `group_id` 仅存储（:212-218）；`select_in_group` 需调用方传 peers（:242-254）→ 缺 参考工具包 `autoExclusive`（同父自动排他）与 button group 等价管理器 → 库内按 group_id 注册表，点击自动互斥。

- [动画] 无 hover/press 过渡（共性 1）。

### ToggleButton (`base_widgets/toggle_button.rs`) ↔ 参考工具包 `tool button`(checkable) — ✅ 已实施
- [属性] `auto_exclusive` 仅意图标志不强制（:172-178）；缺 `icon`/`arrowType`/`menu`/`popupMode`/`autoRaise`。
- [事件] **handle_event 无 KeyPress 臂（:585-630）→ 无键盘激活**；tool button Space/Enter 可 toggle → 补 Space/Enter 臂（Button :909-911 有现成范式）。

- [动画] PropertyDriver（:92, 243-264）≈持平偏优。

- **门控决策（用户确认 2026-10-23）**：上述 P0–P3 全部 3D 能力置于 Cargo feature 门控之后，**默认不编译**：

  - 门控关闭时现有 2D 路径零行为变化、二进制零增量；
  - CI 双矩阵：`--no-default-features` 与 `--all-features` 均须编译通过，防门控腐烂。

**3D 就绪度：1.5/10（真 3D）/ 4/10（伪 3D 可达性）**——口径：矩阵/深度/层合成/shader/光照 5 项基建各 0-2 分。有：完整 2D 命令集、z_index 雏形、bevel/gradient 伪立体资产、成熟 GPU 管理层、offscreen target。无：矩阵数学与顶点变换、depth buffer、仿射以上 Transform 栈、逐层合成与效果管线、光照。

### P0-20（正确性）DiffViewer 逐行位置比较非 diff 算法
- 涉及文件：`src/widget/special_widgets/diff_viewer.rs:109-130`（`recompute` 按索引配对）、`:22`（DiffKind）、`:42`（DiffLine 双 Option 结构）、`:105`（change_count）
- 根因：`(Some(a), Some(b)) if a==b → Equal else Changed` 是逐行位置比较——顶部插入一行即把后续全部误判 Changed。
- 修改方案（Myers O(ND) 贪心 + 线性回溯，落点只在 `recompute`）：
  1. 数据结构（新增私有类型，公开 API 零变化）：
     ```rust
     enum EditOp { Equal(usize, usize), Delete(usize), Insert(usize) } // 左右行号
     fn myers_diff(a: &[&str], b: &[&str]) -> Vec<EditOp>;
     ```
     要点：V 数组按 k∈[-D..=D] 存每轮最远到达 x；逐 D 外层、k 内层（snake 贪心），记录每轮 V 快照供回溯；D 上限设 `a.len()+b.len()` 兑底。

  3. 规模护栏：`(a.len()+1)*(b.len()+1)` 超预算（如 4M 格）时退回现位置比较并在 doc 标注——防病态输入内存爆炸；`recompute` 全量双克隆问题（:125-129）不在本项扩大。
  4. hunk 边界（相邻 Equal 游程 ≤2 行时并入变更块）可作后续，不影响正确性。
- 验收标准：1. 测试：`left="A\nB\nC"`、`right="X\nA\nB\nC"` → 首行 Added，其余 Equal（现实现会输出 4 行 Changed）；2. 全等输入输出全 Equal；3. `change_count()` 与行统计一致。
