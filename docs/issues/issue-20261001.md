## 2. 根因分析与长期防范

1. **宏委托完整性**：
   - 跨包装层使用宏（如 `delegate_widget!`）代理 Trait 时，必须完整覆盖 Trait 的核心方法（特别是提供内部状态引用的 `base(&self)` 和 `base_mut(&mut self)`），并在单元测试中覆盖包装类的基本生命周期与绘制。
2. **UTF-8 字节切片边界防范**：
   - Rust 的 `&str[..N]` 是按字节索引，在截取标题、标签、条码或预览文本时，一律使用 `floor_char_boundary` 截断，杜绝任何字符割裂 panic。
3. **复合状态双向同步**：
   - 类似 `ColorPicker` 同时维护 RGBA 与 HSVA 双重表现形式的控件，所有公开设置入口（`set_color`, `set_hex`, `set_hsva`）必须维持数学等效的双向一致性。
