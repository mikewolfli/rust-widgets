## 第 1 章 运行时与事件热路径（PF4-）

**PF4-01 六个控件的动画 tick 直接调 `request_redraw()`，每帧 bump 全局 `STRUCTURE_EPOCH`，整树 metrics 缓存（RD3-02）被同库新代码击穿**
- **1级** `BaseWidget::request_redraw`（`src/widget/base.rs:1408-1424`）末段无条件 `note_structure_changed()` → bump 全局 `STRUCTURE_EPOCH`（`src/widget/runtime/cache.rs:254-256`）；`:1416-1420` 注释自述契约：「帧总线逐帧动画伤害走 `mark_dirty_rect`，这里 bump 结构代数正是为了让动画帧保住 metrics 缓存（RD3-02）」。但六个控件的 `tick`（由动画 sweep 每帧驱动）恰恰在 tick 内直接调 `self.base.request_redraw()`：`pie_menu.rs:875`、`radar_chart.rs:675`、`mini_chart.rs:536`、`floating_label.rs:343`、`tooltip.rs:396`（`owes_frame` 时）、`progress_dialog.rs:508`（busy 期间每帧必调，时长无界）。`TREE_METRICS_CACHE` 键含 `structure_epoch()`（`render.rs:875`），全局 repaint generation 在纯动画帧内稳定，唯独这个每帧 bump 使键每帧失配 → miss 路径按 `render.rs:869-874` 注释是「整树重预取」。且 `STRUCTURE_EPOCH` 为进程级计数：窗口 A 的一个动画控件同时击穿窗口 B 的 metrics 表。触发频率 = 动画期间每帧，单次成本 O(可见树) metrics 重算——spinner/进度条/tooltip 淡入等任何此类控件出现时，RD3-02 的收益归零。**冰山证据**：另有约 10 个控件已各自实现 `request_frame_repaint(bounds)` 帮助函数（先例 `progress_circle.rs:225-237`，tick 内 `request_frame_repaint(Some(self.damage_bounds()))` `:290-305`；同型 button/arc/progressbar/switch/scrollbar/rating/skeleton_loader 等），窄矩形 `request_repaint_rect` + 保留 `redraw_requested.emit()`、**不** bump 结构代数——这六个是同型残余（call-site 漂移，非机制缺陷）。
- **2级** 为六控件逐一补同款 `request_frame_repaint(Option<Rect>)` 帮助函数（照抄 `progress_circle.rs:225-237` 形制：非 Full 模式走 `request_repaint_rect`，tick 传 `Some(self.damage_bounds())` 以避免 sweep 持注册表时回读几何，未挂载回退 `request_redraw` 保信号契约），tick 内 `self.base.request_redraw()` 改调它。伤害覆盖、信号契约、`RepaintMode::Full` 保底全部不变；零新机制、零重命名，RD3-02 对全控件树恢复生效。

### 14.1 注解 `/P` 与 GoTo `/D` 指向页对象号

- `writer.rs` 在写注解字典**之前**预计算每页的对象号（内容流 + 表单 + 注解 + 链接 + 页对象），`serialize_pdf_annotation(annotation, page_object_id)` 与 `serialize_pdf_hyperlink(link, &page_object_ids)` 均使用解析后的对象号。

### 14.2 R=4 `/O` `/U` 规范派生

- 自实现 **MD5**（RFC 1321 向量）与 **RC4**（经典向量），不新增依赖；移除不再使用的 `sha2`。**（第 16 章已将其替换为审计 crate。）**
- **Algorithm 2**：文件密钥 = 50 轮 MD5(padded user pwd ‖ O ‖ P(LE i32) ‖ ID[0])[..16]（`EncryptMetadata` true）。
- **Algorithm 3**：`/O` = 1+19 轮 RC4(padded user pwd, key=50 轮 MD5(owner pwd)[..16])。
- **Algorithm 5**：`/U` = 1+19 轮 RC4(MD5(padding ‖ ID), file key) ‖ 16 字节随机尾。
- 字典保持 `V4/R4/Length 128/CFM AESV2`；trailer 新增 `/ID [<id> <id>]`（Algorithm 2 必须读它）。**（第 17 章互验修正：V4/AESV2 还需按对象密钥 + `sAlT`，字符串也必须逐对象加密。）**
