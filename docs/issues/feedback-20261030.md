## 1. 控件/视图 API 缺口（阻断宿主"只用上游控件"的硬约束）

### F-1｜`TreeIndex` 需要公开构造器或 ForeignId 泛型（P1）

宿主被迫维护复刻版 `SceneIndex`（`src/app/canvas/scene.rs:36-43,200-212`，模块文档自认"等待上游公开
构造器"）。原因：钉定修订暴露的 `TreeIndex` 是只读快照，`build` 构造器为 `pub(crate)`
（`src/view/identity.rs:185`），唯一公开生产者 `ViewEngine::tree_index` 走已挂载声明树并存储引擎
`ObjectId(u64)`；设计画布不挂在 ViewEngine 且持有持久 `NodeId`，无公开 API 可把宿主 id 树交给 `TreeIndex`。

**建议**：暴露 `TreeIndex<Id>` 泛型或公开 builder，使宿主 `SceneIndex` 退役（上游 #59：同一概念不留平行路径）。

### F-2｜`create_widget_of_kind` 在 native desktop 后端返回 0（P1）

宿主只能改走 control backend 路线（`get_control_backend_for_widget(WidgetKind::Canvas).create_canvas`，
`src/app/run/workbench_gui.rs:2720-2726`），即 per-widget 平台 surface 挂载路线。
**建议**：让该入口在 native 后端可用，或把 control backend 路线写成公共契约（上游 #41：机制选择属
platform backend，但选择结果应可发现）。

### F-3｜`WidgetFactory::shared` 不可扩展，套件控件对共享表不可见（P1）

套件控件（`form`/`form_set`，上游同仓库子包 rust-widgets-suites）不在 `WidgetFactory::shared` 的
构造名集合里，宿主被迫自建工厂再安装套件（`src/app/contract.rs:6-11,36-42`）。
**建议**：提供可注册扩展的工厂构造入口，避免宿主工厂与 shared 表漂移（上游 #59）。

### F-4｜ToolButton 缺图标颜色通道（P2）

宿主注释明言 "There is no icon-colour setter"，角色色只能整控件文本色（`src/app/shell/toolbar.rs:33-39`）。
**建议**：ToolButton 增加 icon tint/role setter。

### F-5｜`mouse_pressed/mouse_released` 事件不带坐标（P2）

宿主只能用 `mouse_moved` 维护指针位（`src/app/run/workbench_gui.rs:2737-2740`），拖拽起点/终点精度受损。
**建议**：press/release payload 附带位置。需运行核实 payload 确无坐标后定稿。

### F-6｜theme 管理器互斥锁不可重入（P2）

调用方需手工防死锁（宿主把 backdrop 与 accent_surface 拆成两次取锁，`src/app/shell/toolbar.rs:412-415`）。
**建议**：提供快照式读取 API 或可重入守卫。

### F-7｜平台层缺显示器枚举（P2）

多窗口/窗口放置能力缺口，宿主留有记录（`src/app/shell/windows.rs:24`）。
**建议**：platform trait 增加显示设备枚举（诚实默认 `None` 亦可，见上游 #37–#38）。

### F-8｜设计器契约无 category 字段（P2）

面板只能按 kind 拼写分组（宿主 `src/app/canvas/widget_catalog.rs:258-265,696-698`）。
**建议**：designer manifest 增加设计器分类字段（能力往返语义仍满足上游 #96）。

### F-12｜`CommandPalette` 没有 dismissed/close_requested 信号（P2）

宿主 W-2a 已改用上游 `CommandPalette`（`rw/src/widget/special_widgets/command_palette.rs:161`）。
控件的 Escape 只执行 `clear_query()`（:1022），不发出任何“用户要求关闭”的事件；宿主只能靠
`focus_lost` 关闭（点击别处）或菜单/工具栏再次触发。自拼装 LineEdit 版本用 `editing_finished`
即可关闭，换成上游控件后失去该行为。
**建议**：Escape 清空查询后发出 `dismissed`（或 `close_requested`）信号，让宿主保留
“Escape 关闭命令面板”的既有交互。

## 2. i18n 能力建议（宿主将按 JSON 语言包 + 热加载消费）

上游 `src/i18n/`（mod.rs:4 自述 "internationalization support with hot reload"）已具备：JSON
`TranslationFile/Translation`（types.rs:11-45）、`load_translations`/`inject_translations`
（manager.rs:244/286）、`set_language`（:290）、`translate(_with_context)`（:313/:330）、`audit_keys`（:298）、
`I18nFileWatcher`+`pump_hot_reload`（watcher.rs:83/501）。以下是消费侧发现的三个缺口：

### F-9｜缺 `{name}` 模板占位符替换（P2）

上游 `src/i18n/` grep `placeholder|interpolat` 无命中，仅 context/plural；宿主自有
`Catalog::fill` 模板填充（`src/app/locale/catalog.rs:295-310`），迁移到上游 i18n 后仍需保留自研 fill 层。
**建议**：`translate_with_context` 支持参数插值，或提供配套填充 API，使宿主可整体退役自研层（上游 #59）。

### F-10｜缺"跟随系统语言"探测（P2）

`InitOptions.language` 需调用方给定（options.rs:13-20），无 `LC_ALL/LC_MESSAGES/LANG` 读取；
宿主已有实现（`src/host/locale.rs:126-133`）。属宿主可自持的弱需求，反馈供上游对齐，不阻塞。

### F-11｜缺"加载期按 key 集合完整性校验"（P3，弱需求）

`audit_keys`（manager.rs:298）是事后审计；无"语言包 vs 词条集合双向比对、缺 key 拒载"的加载语义。
宿主目前以编译期测试强制（`src/app/locale/zh_hans.rs:11-19`）。不强求，记录备忘。
