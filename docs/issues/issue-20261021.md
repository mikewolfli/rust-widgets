## 1. 高频根因聚类（跨分区合并视图）

> 本节的目的是把“一个修复能闭合多条编号”的项显式列出，避免修复时按编号逐个打补丁（原则 #17/#101）。

### T1 · 控件能力工厂被重复重建（**最高优先级，一处修复闭合 7 条**）

- **涉及**：`CORE-01` ≡ `WBASE-01` ≡ `BIND-01` / `BIND-02` / `BIND-03` / `BIND-04`；`BIND-08` 为其衍生。
- **根因**：`WidgetFactory::new_with_defaults()`（`src/widget/capability.rs:292`，内部 `registration.rs` 约 190 次 `register`，每次 `normalize_key` 分配 String + 2 次 HashMap 插入）在**每次调用**时重建整张能力表。
- **热调用点**：
  - 属性读写：`src/app/handle.rs:4063,4089`（全部约 25 个 handle 访问器）；
  - hover/press 状态机：`src/widget/widget_trait.rs:281-299` → 主题重解析 → `factory_name_for_kind`；
  - 控件创建/换肤：`src/theme/apply.rs:67-77`、`src/lib.rs:1200-1205,1255-1265,1403`；
  - view diff：`src/view/diff.rs:251-260,276-286,310-315,386-390,544-548`；
  - JSON 加载：`src/json/loader.rs:147-171,454-474`、`src/json/event_route.rs:351-386`。
- **修法**：把默认工厂放进 `thread_local!`/`OnceLock`（构建后只读；`capability()/property_schema()` 均为 `&self`），全部调用点改走缓存。**预估收益最大、改动最局部**。

### T2 · 空闲期忙轮询（事件循环 / 平台后端）

- **涉及**：`CORE-02`（`src/event/loop.rs:663-664`，1ms sleep）、`PLAT-01`（9 个平台后端 16ms `PeekMessage`+sleep）、`PLAT-07`（Wayland 回退臂纯空转）。
- **根因**：事件循环通过“固定间隔醒来 + 无条件推进帧”代替“等待事件/截止时间”；`drive_frame` 已返回是否需要下一帧，信息未利用。
- **修法**：Windows 用 `MsgWaitForMultipleObjectsEx`；其余后端改 `Condvar::wait_timeout` / 事件队列唤醒；`needs_another_frame == false` 时阻塞而非 sleep。见各条。

### T3 · UI 线程同步阻塞（子进程 / D-Bus / 首用探测）

- **涉及**：`PLAT-03` ≡ `MEDIA-04`（打印提交最长 30s×2）、`PLAT-02`（每帧 spawn `ps`）、`PLAT-04`（打印能力探测每次 spawn）、`PLAT-05`（IME/AT-SPI 同步 D-Bus 往返）、`PLAT-06`（每次 `pmset`）、`PLAT-10`（首用 `fc-list`）、`PLAT-12`（Wayland 剪贴板 poll 500ms）、`MEDIA-03`（音视频/图片解码同步执行）。
- **根因**：平台能力探测与设备 IO 直接在调用线程同步完成，缺少“缓存 + 后台线程 + 事件回填”三件套。
- **修法**：探测结果 `OnceLock` / TTL 缓存；提交类操作 fire-and-forget 或移后台线程经信号回报；macOS 用 `mach_task_basic_info` / `IOPSCopyPowerSourcesInfo` 消除子进程。

### T4 · 每帧 / 每元素分配（模式类，覆盖面最广）

- **涉及**：`CORE-03`（动画帧事件）、`CORE-05`（信号发射）、`CORE-07`（定时器）、`CORE-14`（触摸翻译）、`CORE-20`；`WBASE-05`（`children().to_vec()`）、`WBASE-08/09`；`WDGT-02/04/05/06/07/08`；`REND-03/04/08/13/14`；`BIND-07/09/10/11`；`MEDIA-05/06/15`。
- **根因**：绘制/布局/事件路径上按值返回 `String`/`Vec`/`WidgetStyle`，或为借用检查用 `collect` 中转；部分缓存“命中即深拷贝”。
- **修法**：借用优先（`Cow`/`&str`/`Rc`），栈上格式化（`core::fmt::Write`），thread_local scratch 复用，缓存值改 `Rc`。建议作为**一批**统一治理。

### T5 · 缺缓存导致的重复计算

- **涉及**：`WDGT-01`（TextEdit 每次重排）、`WDGT-03`（TextArea 行扫描）、`REND-05`（CSS 每控件重解析）、`REND-06`（for_state 样式无缓存）、`REND-09`（渐变每像素扫 stops）、`WBASE-03/04`、`MEDIA-01/02/08`。
- **根因**：可失效的派生数据（行起点、CSS 规则、resolved style、IDCT 系数、Huffman 表）在热路径反复重算。
- **修法**：引入 `(rev, geometry)` 为键的缓存或 `const` 表，统一“变更时失效”。

### T6 · O(n²) / 线性查找（数据量放大即卡顿）

- **涉及**：`CORE-04`（mini 出队）、`CORE-06`（`Vec::remove(0)`）、`WBASE-02`（重绘台账 `Vec::contains/find`）、`BIND-03`/`REND-07`（view diff 位置匹配）、`WDGT-09`（选中集 contains）、`MEDIA-08`（LZW 字典）、`CORE-16/17`。
- **修法**：`HashMap`/`HashSet`/`BinaryHeap`/`VecDeque` 替换线性结构；利用已排序不变量改 `binary_search`。

### T7 · API 一致性与“美观”（属性/方法层）

- **涉及**：`WDGT-12`（`set_text` 四种签名）、`WDGT-13`（选中项四种命名/三种类型，含 `i32` −1 哨兵）、`WDGT-14`（`insert_text` vs `insert_str`）、`WDGT-15`（setter 无等值短路）；`BIND-13`（通配导出）、`BIND-14`（同名枚举多份）；`PLAT-13`（文件命名误导）、`PLAT-15`（巨型 types.rs）；`CORE-18`（伪表达式）。
- **修法**：先定规范再动（涉及公开 API 需 `#[deprecated]` 过渡），优先统一 `set_text` / `selected_index() -> Option<usize>` / `insert_str` 三组。
